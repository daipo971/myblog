## 许可证与商用

- **开放权重用 MIT 协议**：GLM-5.3-Flash 的模型卡明确标注 MIT，5.1、4.5 系列同样以 MIT 开源。这意味着下载权重后可以商用、可以二次开发、可以部署在自己的服务器上，成本只剩下算力。
- **注意例外**：垂直模型不一定开源。GLM-Legal 目前只开放 API 申请试用，权重未开放，商用前要先确认所用版本的状态。
- **合规提醒**：MIT 协议宽松，但不等于没有义务——保留原始 LICENSE 声明是基本要求；面向国内用户提供服务时，生成式 AI 备案等合规事项与模型许可证是两回事，要分开处理。

## 怎么用

### 国内用户

- **日常对话**：用「智谱清言」App 或网页版，注册即用，适合问答、写作、学习等通用场景。
- **开发调用**：走国内开放平台（bigmodel.cn），人民币结算，支持 GLM 全系列 API；国际站 Z.ai 则以美元结算，两个站点的账号与余额不通用，选定一个再充值。
- **写代码**：GLM Coding Plan 面向编程场景，含编码平台接入；已有编程工具的开发者也可以直接调 API，把 GLM-5.3 或 5.3-Flash 接进自己的工作流。
- **本地部署**：权重开源，可用 SGLang、vLLM 等主流推理框架跑。旗舰 744B / 320B 级别体积大，个人电脑基本跑不动，需要多卡或量化版本；轻量版 Air、Flash 更适合个人与小团队自托管，具体显存需求以官方部署文档为准，本文不给未经核实的配置数字。

### 海外用户

- 国际站 Z.ai 直接开 API 账号，美元结算；也可以通过 OpenRouter、AWS Bedrock 等第三方托管渠道调用，价格与延迟以托管方为准。
- 开源权重同样适用：从 Hugging Face 的 zai-org 组织下载，按 MIT 协议自托管。

## 实测与评价

以下均为官方说法或第三方榜单数据，非本站实测，引用时请注意口径：

- **GLM-5.1 的编程高点**：官方称 SWE-Bench Pro 58.4 分，发布时超过同期的 GPT-5.4、Claude Opus 4.6 与 Gemini 3.1 Pro，刷新全球最佳；这是智谱自己定义的评测环境，外界无法完全复现，参考时打个折。
- **GLM-5.3 的编程认可**：据公开资料，GLM-5.3 在 CursorBench 4.0 拿下开放权重模型最高分 42.6%，并获 Cursor 接入。
- **GLM-5.3-Flash 的综合能力**：据媒体报道，该模型在 Artificial Analysis 综合智能指数中取得 57 分，与 Claude Opus 4.8 持平；同时官方强调其架构为极低成本而设计：总参数与 GLM-4.5 相当，激活参数与层数几乎减半，并首次引入稀疏注意力与线性注意力混合架构。
- **GLM-Legal 的法律表现**：在 Harvey LAB 24 类法律业务评测中任务通过率 19.2%，较基线提升近 3 倍，详见本站解读文章。
- **横向定位**：GLM 的长处是编程与长程 Agent 任务，价格带覆盖从免费到旗舰；短板是 5 系旗舰的绝对能力仍未公开证明全面超过闭源最强模型，选型时按任务而不是按名气。

## 常见问题

**GLM 和智谱清言是什么关系？**

智谱（Z.ai）是公司，GLM 是模型家族，智谱清言是面向普通用户的对话产品，底层用的就是 GLM 模型。普通用户用清言，开发者调 GLM API。

**GLM 免费吗？**

分三层：智谱清言有免费档；API 有免费模型（4.5-Flash、4.7-Flash、4.6V-Flash），但限速；旗舰与主力模型按 token 收费。免费档适合尝鲜，正式项目要按量付费。

**GLM 权重开源，能商用吗？**

5.x 与 4.5 系列权重以 MIT 协议开源，可以商用和二次开发；但每个模型仓库的 LICENSE 为准，垂直模型如 GLM-Legal 目前不开放权重。

**国内开发者用哪个平台？**

日常对话用智谱清言；开发调用优先看国内开放平台 bigmodel.cn（人民币结算），国际站 Z.ai 以美元结算，两边账号余额不通用。

**GLM-5.3-Flash 和 GLM-5.3 怎么选？**

Flash 是轻量多模态版，价格约旗舰十分之一，适合成本敏感、需要图文理解的场景；旗舰 5.3 适合对编程与长程任务能力要求最高的场景。同一任务可以先拿 Flash 跑通，不够再升级旗舰。
