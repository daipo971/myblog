.com 域名正常注册一年要十几美元。昨天实测了一条野路子：**Google Workspace 土耳其区买域名，.com 首年只要 ₺75 土耳其里拉（约合人民币 10 块钱）**。xinqai.com 就是这么拿下的，全程手机操作，半小时搞定。

原理一句话：Google Workspace 在不同地区定价不同，土耳其区的域名注册费低得离谱。关键是——**域名是单独计费的**，跟 Workspace 订阅是两码事，订阅取消了，域名照样在你名下待满一年。

## 操作流程

### 准备工作

- 土耳其 IP（重点，后面细说）
- 一张能刷外币的卡（Visa / Mastercard 都行）
- 一个常用邮箱（收验证邮件）

### 注册步骤

1. 土耳其 IP 下打开 Google Workspace 注册页，地区选土耳其，开通试用
2. 注册流程里直接购买域名，.com 显示 ₺75/年，按提示填信息、付款
3. **去邮箱点 ICANN 验证邮件**——这封必须点，不点域名会被暂停解析
4. 域名到手后，第一时间把 NS 转到 Cloudflare 自己管理（Google 只是代注册，DNS 拿在自己手里最稳）
5. 绑定到你的建站平台（我是绑的 Cloudflare Pages，自动部署）

## 避坑指南（重点）

### 坑1：IP 风控

美国机房 IP 注册会被限流卡住。实测：云服务器 IP 直接被 throttle，换手机流量 IP 一次通过。**一定要用住宅 IP 或手机流量**，别在服务器上硬刚。

### 坑2：别编假地址

账单信息如实填。Google 风控很严，虚假身份信息可能导致账号被封、域名被收回——为省 10 块钱丢账号，不值。

### 坑3：取消订阅前，先备份邮箱（我亲身踩的坑）

域名到手后我取消了 Workspace 试用订阅，第二天发现 Workspace 的邮箱空了。先说结论：**这是正常机制，不是 bug**——取消订阅会停用并删除 Workspace 托管的邮箱，删的是邮箱，不是你的域名。

正确姿势：

- 取消前把重要邮件（付款收据、ICANN 验证信、账号信息）截图或转发到自己的常用邮箱
- 冷知识：付款收据在 pay.google.com 的付款账号里，不在 Workspace 邮箱里，取消订阅不受影响，随时能查到

### 坑4：取消订阅，域名不受影响（但别手滑）

再强调一次：**域名和 Workspace 订阅是两笔独立的账**。取消订阅后：

- 域名照常有效一年（我查了注册局 RDAP 数据，到期日 2027-10-16，一天没少）
- 邮箱、网盘等 Workspace 服务会被停用
- 千万别在取消时顺手把"域名注册"这个订阅也点了——Admin 后台里它们是分开列的，认准再点

### 坑5：续费

- 域名续费走 Admin 后台里单独的"域名注册"订阅，和 Workspace 订阅无关
- 续费价可能浮动（里拉汇率波动大），明年续费前先看一眼账单确认金额
- 到期前记得续，.com 掉了被别人抢注就搞笑了

### 坑6：试用期取消，订阅费不收、域名费不退

试用期内取消，Workspace 订阅本身不扣钱；但 ₺75 域名注册费是实打实花出去的，不退。不过 10 块钱买个 .com，还要啥自行车。

## 适合谁

- 想低成本拿 .com 做个人站、博客的人
- 有外币卡、不怕折腾的人

不适合：完全不想碰英文后台、对账号风控零容忍的人。

## 一句话总结

土耳其 IP + 外币卡 → Workspace 试用 → ₺75 买域名 → 点 ICANN 验证 → 转 Cloudflare 自管 → **备份邮件** → 取消订阅。域名一年有效，邮箱会清空，提前备份就行。

## 把 DNS 交给 Cloudflare：详细步骤

域名到手后第一件事是把解析权拿到自己手里，以后换建站平台、加邮箱记录都不依赖 Google Workspace。

1. 登录 Cloudflare，点 **添加站点**，输入刚买的域名，选 Free 套餐。
2. Cloudflare 会扫描现有的 DNS 记录，确认无误后继续，页面会给出两个 Cloudflare 的名称服务器（NS）地址。
3. 回到 Google Workspace 管理后台，进入 **域名 → 管理域名**，找到这个域名的高级 DNS 设置，切换到使用自定义名称服务器，填入 Cloudflare 给的两个地址并保存。
4. 等待生效，通常几分钟到几小时，最长可能要 24–48 小时。Cloudflare 检测到后会发邮件通知站点已激活。
5. 在 Cloudflare 里添加建站平台需要的记录，比如 Cloudflare Pages 的自定义域名会自动帮你添加 CNAME。

改 NS 之前，如果还想保留 Workspace 邮箱，先把 Google 给的 MX 记录抄下来，在 Cloudflare 里原样添加，否则邮件会收不到。

## 成本算一笔账

| 项目 | 土耳其区 Workspace 路线 | 常规注册商路线 |
| --- | --- | --- |
| .com 首年 | ₺75（按当时汇率十几元人民币） | 一般十几美元 |
| 续费 | 走 Workspace 后台单独的域名订阅，价格随里拉汇率浮动 | 按注册商的续费价，相对稳定 |
| 操作难度 | 需要土耳其网络环境、外币卡、英文后台 | 注册、付款、管理都简单 |
| 风险 | 地区定价规则可能调整，账号受 Google 风控约束 | 基本没有额外风险 |

如果只是想省首年的钱，这条路线确实划算；如果想长期稳定持有一个重要域名，第二年到期前可以考虑转移到常规注册商，转移时一般会顺带续费一年。

## 常见报错与解决

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| 注册页一直转圈或提示稍后再试 | 机房 IP 被限流 | 换成手机流量或住宅网络，不要用云服务器 IP |
| 付款失败 | 卡不支持外币或被发卡行风控拦截 | 换一张支持外币的卡，或提前在发卡行开通境外交易 |
| 域名能打开但几天后失效 | 没点 ICANN 验证邮件，域名被暂停解析 | 去邮箱找验证邮件点击确认，找不到就在后台重新发送 |
| 改了 NS 还是不生效 | DNS 缓存未过期 | 耐心等待；用在线 DNS 查询工具确认 NS 是否已变成 Cloudflare |
| 取消订阅后邮箱数据没了 | 取消 Workspace 会停用邮箱 | 取消前备份重要邮件，付款记录到 pay.google.com 查 |

## 常见问题

**只买域名，不用 Workspace 可以吗？**
可以。按本文的做法，开通试用并买下域名后取消 Workspace 订阅，域名照样有效一年，只是邮箱和网盘不能再用。

**一个 Workspace 账号能买多个域名吗？**
本文只验证了购买一个域名的流程，多个域名的规则没有测试，建议以后台实际显示为准，不要为了囤域名反复注册账号。

**第二年续费会涨价吗？**
可能会。续费价按里拉计价，汇率波动大，Google 也可能调整地区价格。到期前一个月看一眼后台账单。

**域名可以转出到别的注册商吗？**
一般可以。新注册的域名通常要满 60 天才能转移，转出前在 Workspace 后台解锁域名并获取转移授权码。

**国内能用这个域名建站吗？**
域名本身可以正常使用。如果网站服务器在中国大陆，需要按规定办理备案；用 Cloudflare Pages 这类海外托管不涉及备案。建站流程见 [从零搭建个人博客](/posts/free-blog-tutorial/)。
