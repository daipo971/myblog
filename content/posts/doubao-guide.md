## 許可證與商用

- **語言模型不開放權重**：Seed 2.1 系列目前沒有公開的權重下載管道，開發者只能通過方舟 API 調用。這意味著不能像 GLM、Kimi 那樣把模型搬到自己的伺服器上跑，成本與可用性完全取決於方舟。
- **商用走 API 協議**：調用 API 商用時，權利義務以火山引擎的服務協議與模型使用條款為準，不要把「能調用」理解成「擁有模型」。
- **影片與圖片模型同理**：Seedance、Seedream 同樣是 API 與 App 內服務，沒有開放權重；生成內容的商用授權以各產品的服務條款為準，商用前先確認。
- **合規提醒**：面向國內用戶提供服務時，生成式 AI 備案等合規事項與模型授權是兩回事，要分開處理。

## 怎麼用

### 普通用戶

- **日常對話**：用豆包 App 或網頁版，登錄即可對話，適合問答、寫作、學習等通用場景；App 內可切換影片與圖片生成能力。
- **辦公任務**：豆包電腦版或 App 的「辦公任務」模式可體驗 Seed 2.1 的 Agent 能力，適合多步驟任務的嘗試，複雜任務仍建議人工檢查結果。
- **影片與圖片**：在豆包 App 對話框選擇 Seedance 模型生成影片，或用圖片生成功能改圖；單次生成時長與參考素材上限以 App 內實際說明為準。

### 開發者

- **調用 API**：走火山方舟，Base URL 為 `https://ark.cn-beijing.volces.com/api/v3`，兼容 OpenAI SDK；新項目直接用推薦版本 `doubao-seed-2-1-pro-260915`，不要用已過期的 260628 快照。
- **寫代碼**：TRAE 已接入 Seed 2.1 Pro（0915 版），方舟 Coding Plan 個人版也支持 Pro 與 Lite；編程場景優先看 Coding Plan 的額度檔位，再決定按量還是訂閱。
- **長上下文任務**：需要一次讀入大量資料時選 Pro（1024K）或 Evolving（1M），不要用 Turbo 的 256K 硬塞；輸入超長時先評估緩存命中對成本的影響。

### 海外用戶

- **走 BytePlus ModelArk**：海外目錄用 `seed-*` 開頭的模型 ID、美元結算，與國內方舟的 `doubao-seed-*` 目錄不完全對應，選型前先核對 ModelArk 當前列表。
- **不要跨區混用 ID**：國內方舟的模型 ID 拿到海外端點不一定存在，反之亦然；代碼裡的 Base URL 與模型 ID 必須成對更換。

## 常見問題

**豆包、Seed、火山方舟是什麼關係？**

豆包是面向普通用戶的 AI 助手產品；Seed 是字節跳動的模型研發團隊與模型系列名；火山方舟（Ark）是火山引擎上提供模型 API 的平台。普通用戶用豆包，開發者調方舟上的 Seed 模型。

**豆包免費嗎？**

分兩層：豆包 App 日常對話登錄即可使用，具體權益以 App 內說明為準；開發者調用方舟 API 按 token 收費，沒有全免費的旗艦檔，正式項目要按量付費。

**豆包的模型能下載到本地跑嗎？**

目前未見語言模型的開放權重下載，本地部署路線不適用；需要自託管的團隊應選 GLM、Kimi 等開放權重的家族，而不是豆包。

**Seed 2.1 Pro 的 260915 和 260628 有什麼區別？**

260915 是 0915 推薦版本，上下文 1024K；260628 是較早快照，上下文 256K；兩者官方單價相同，新項目一律用 260915。

**國內開發者與海外開發者入口一樣嗎？**

不一樣：國內走火山方舟（`doubao-seed-*`、人民幣結算、需實名），海外走 BytePlus ModelArk（`seed-*`、美元結算），模型 ID 與 Base URL 都要成對更換。
