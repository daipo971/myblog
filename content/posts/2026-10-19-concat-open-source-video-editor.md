> **测试方法说明：** 本文基于 Concat 的 GitHub 仓库说明、Releases 页面和官网文档整理（2026 年 10 月，0.2.x 版本），对照剪映的公开功能做对比；性能和稳定性部分来自官方说明和社区反馈，没有做系统的跑分测试。

这几天剪映把一批功能转付费、订阅涨价的消息传出来，评论区一片哀嚎。巧的是，就在这两天，一个开源剪辑工具 **Concat** 在 GitHub 上火了——9000 多 star，号称"免费、开源、跨平台的 CapCut 替代品"，而且它的 AI 字幕、配音、去背全在本地跑，不用联网、没有水印。

我把它翻了个底朝天，这篇讲清楚：它到底能做什么、跟剪映比差在哪、值不值得你现在换。

## 一句话介绍

Concat（GitHub：jub0t/Concat）是个免费开源的视频编辑器，定位就是剪映/CapCut 的平替。AGPL-3.0 协议，个人用完全免费。支持 macOS、Windows、Linux、Android、iOS，有简体中文。

它的口号很直白：**无水印、无需账号、无需订阅、不上传**。所有东西都在你自己电脑上跑。

## 核心功能：剪映的活，它基本都能干

- **自动字幕**：本地 Whisper 模型，选个模型大小，带样式的字幕直接排进时间线。中文识别是 Whisper 的强项。
- **文字转语音 + 声音克隆**：免费的本地声音，或者录几秒钟音频克隆任何声音——做旁白、配音不用再找第三方工具。
- **背景移除**：人物、物体一键去背，也可以自己涂抹遮罩。
- **多轨剪辑 + 关键帧**：位置、缩放、旋转、不透明度、音量、特效参数都能打关键帧，还带曲线编辑器。
- **100 种特效、滤镜和转场**：GPU 渲染，预览实时。
- **一键人声净化**：降噪、增强人声、响度均衡，还有变声效果。
- **导出**：H.264、HEVC、AV1，最高 **4K 60fps、10-bit 色彩**。

AI 模型只需要在设置里下载一次，之后**断网也能用**。你的素材永远不会离开硬盘——这点对在意隐私的人很友好。

## 最特别的一点：AI 可以直接拿它剪视频

这是 Concat 跟所有剪辑软件都不一样的地方：它**自带 MCP server**，还提供 JSON-RPC API。什么意思？Claude 这类 AI agent 可以直接调用它来剪视频——选片段、加字幕、套转场，都不用你动手。

如果你在玩 AI 自动化工作流（比如"睡前丢个指令，醒来视频剪好了"），这可能是目前最顺手的一块拼图。当然，这功能偏极客，普通用户先当它不存在就行。

## 怎么下载安装

两个入口：

1. **官网** concatenate.pages.dev，会自动给你对应系统的版本，新手从这里开始。
2. **GitHub Releases**（jub0t/Concat），每个平台的安装包都在，适合想自己挑版本的人。

几点安装提醒：

- **Windows 用户**：安装包目前没签名，SmartScreen 会拦截，点"更多信息"→"仍要运行"即可。作者说了签名政策，暂时就是这样。
- **macOS 用户**：如果系统拒绝打开未签名应用，终端跑一行 `xattr -dr com.apple.quarantine /Applications/Concat.app`。
- **Linux**：有 .deb、.rpm、AppImage 和 Arch 包。
- **手机**：Android 有 APK，iOS 需要侧载。

## 本地处理到底好在哪

剪映、必剪这类工具的很多 AI 功能需要把素材上传到云端处理。对大多数人这不是问题，但有几类人会很在意：拍摄客户项目、内部培训、未公开产品的创作者，素材按合同不能外传；拍家人孩子日常的 Vlog 作者，不想把私人画面交给第三方；网络环境差的人，上传几个 G 的素材本身就很痛苦。Concat 的字幕、配音、去背全部在本机完成，模型下载一次后可以离线使用，这几类需求都能满足。代价是吃电脑配置，以及要自己承担模型下载的时间。

## 实话实说的短板

优点讲完，该泼冷水了：

1. **还是 beta 版**（目前 0.2.x）：作者自己都说"能用，但还有毛边"。有 deadline 的活，建议先留个备用剪辑软件。
2. **AI 模型要下载几个 GB**：字幕、语音、去背的模型各是各的，第一次配置要花点时间。
3. **吃配置**：4K 素材 + 本地 AI 推理，中端显卡会有压力。老电脑建议先拿 1080p 试试。
4. **没有模板库**：剪映的模板、特效库、协作功能，这里一概没有。从零剪起，适合有剪辑基础的人。
5. **社区还在长大**：教程和插件生态不如剪映，遇到问题主要靠 GitHub Issues 和 Discord。

## 适合谁 / 不适合谁

**适合**：不想为剪辑软件付订阅费的人；在意隐私、不想把素材上传云端的人；玩 AI 自动化、想让 agent 直接剪视频的极客；Linux 用户（剪映可没有 Linux 版）。

**不适合**：重度依赖剪映模板、特效库的人；电脑配置比较老的人；赶 deadline、容不得 beta 版小 bug 的商单。

## 一句话总结

剪映涨价潮里，Concat 是目前完成度最高的开源平替——**免费、无水印、本地 AI、还能让 AI 直接剪片**。beta 版有毛边是真的，但方向是对的。先装上试试，剪条 vlog 足够了；等它再成熟几个版本，剪映可能真要紧张了。

## 从剪映迁移要注意什么

- **旧项目带不过来。** 剪映的工程文件不能直接导入 Concat，正在剪的项目最好在剪映里做完，新项目再换。
- **素材要自己备好。** 剪映里用惯的贴纸、花字、音效、背景音乐，在 Concat 里都没有，需要自己准备免版权素材。
- **字幕要多校对一遍。** 本地 Whisper 模型的中文识别不错，但专有名词、口语化表达、方言仍然会出错，小模型错得更多。
- **手机剪辑习惯要改。** Concat 以电脑端为主，习惯在手机上剪完直接发的人，换过来会有落差。
- **留一个备用方案。** beta 版可能出现崩溃或导出失败，重要项目随时保存，并保留剪映作为备用。

迁移最省心的方式是双轨并行一段时间：日常小视频用 Concat 练手，商单和赶时间的活继续用熟悉的工具，等 Concat 出了稳定版再全面切换。

## 第一次上手：剪一条带字幕的视频

1. 从官网下载对应系统的安装包，按上文提醒处理系统的安全拦截。
2. 打开软件，进设置下载需要的 AI 模型：先只下自动字幕用的 Whisper 模型，电脑配置一般就选小一点的模型。
3. 新建项目，把素材拖进时间线，剪掉不要的片段。
4. 运行自动字幕，检查一遍错别字和专有名词，调整字幕样式。
5. 需要的话用人声净化处理一下音频，再加转场和背景音乐。
6. 导出：发短视频平台选 H.264、1080p 就够了，兼容性最好；要存档或上传 YouTube 可以选更高画质。

建议先用一条不重要的素材完整走一遍流程，熟悉之后再用它剪正式的内容。

## 常见问题

**Concat 能完全替代剪映吗？**
看你怎么用。只做基础剪辑、字幕、配音，Concat 已经够用；依赖模板、特效素材库和手机端快速出片的，暂时还离不开剪映。

**AGPL-3.0 协议对个人用户有影响吗？**
个人用它剪视频没有影响，剪出来的作品归你自己。AGPL 主要约束的是修改它的源代码并对外提供服务的情况，需要公开修改后的代码。

**电脑配置不够怎么办？**
先用 1080p 素材，AI 模型选小尺寸，关掉不用的实时预览特效。4K 素材加本地 AI 推理对显卡要求较高。

**安装包没签名，安全吗？**
未签名只说明作者没有购买系统的代码签名证书，不代表有问题，但也意味着系统无法帮你验证来源。务必只从官网或 GitHub 官方仓库下载。

**怎么让 Claude 这类 AI 直接剪视频？**
Concat 自带 MCP server，支持 MCP 的 AI 工具可以连接它来调用剪辑功能，具体配置方法看仓库里的文档。这个功能偏极客，适合已经在用 [Claude Code](/posts/claude-code-codex-cli-2026/) 等工具做自动化的人。
