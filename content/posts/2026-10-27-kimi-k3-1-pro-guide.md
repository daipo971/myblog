结论先行：**10 月 23 日，月之暗面发布了 Kimi K3.1 Pro**——国产大模型里第一个「3T 级」选手，官方成绩单上编程、金融文档、长上下文多项指标摸到了 Claude Opus 5.5 的水平，API 价格却只有 Opus 的一半。最关键的是：**它是国产的，国内直接用，不用翻墙**，网页、App、桌面端、编程助手全渠道同一天上线。

这篇上周五还在候选里（当时只是传闻没官宣，按规矩没写），现在官宣了，补上这篇保姆级上手指南：它强在哪、跟 MiniMax M3.1 Flash 怎么选、普通人从哪免费用、会员怎么买不踩坑。

## 一句话看懂 K3.1 Pro：3T 参数，但每次只用 3%

先把这个「3T」翻译成人话。K3.1 Pro 是**混合专家模型（MoE）**：总参数约 2.8 万亿，里面有 896 个「专家」小模型，但你问一个问题时，**每次只激活其中 16 个**（约 1000 亿参数在干活）。

好处是：模型脑子很大（知识面广），但单次计算量可控（跑得动、成本低）。这是它敢把 API 价格打到 Opus 5.5 一半的底气。

另外两个硬指标：**100 万 token 上下文**（一次能吞下一整本书+代码库），**多模态输入**（文字、图片、视频都能喂）。

## 成绩单：官方自测很亮眼，先看再信

官方公布的成绩（注意：**全是月之暗面自己测的**，独立机构还没复核，看个方向就行）：

- **编程 Terminal-Bench 4.0：65.7%**，Claude Opus 5.5 是 66.4%——咬得很紧；
- **3D 建模代码 BenchCAD：92.7%**，这是它最出彩的一项，接近第一梯队；
- **金融文档 OfficeQA Pro v2：64.4%**，官方称是同类最佳，示例里能生成带可追溯公式的完整财务模型；
- **幻觉率**：在自家最难的事实准确性测试上，从 K3 的 23.4% 降到 **8.3%**。

实话：8.3% 这个数字来自「压力测试集」，不代表日常问答的出错率；厂商跑分和独立评测之间永远有温差。**选模型别只看跑分，拿你自己的真实任务试一轮最准。**

## 跟 M3.1 Flash 怎么选：同一天发布的国产双子星

10 月 23 日是国产大模型日：MiniMax 的 M3.1 Flash 权重也在同一天放出。两者的定位不一样：

| | Kimi K3.1 Pro | MiniMax M3.1 Flash |
|---|---|---|
| 路线 | 全能旗舰：编程、文档、长上下文、Agent | 快而便宜：速度 3 倍、成本降 70% |
| API 价格（输入/输出，每百万 token） | $2 / $10 | $0.15 / $0.60 |
| 权重开源 | 承诺 11 月 4 日前放出 | 已放出 |
| 适合谁 | 要效果、写代码、做文档、跑 Agent | 要速度、要便宜、高频调用 |

一句话：**不差钱要效果，K3.1 Pro；要便宜要快，M3.1 Flash。** 普通用户直接在 Kimi App 里用，根本不用纠结 API 价格。

## 普通人怎么用上：五个入口，同一天全开

这次发布是「托管先行」——**不用等权重下载**，发布当天五个渠道全都能用：

1. **网页 kimi.ai**：打开就能聊，注册用手机号就行；
2. **手机 App**：iOS、安卓、鸿蒙（HarmonyOS）全有，应用商店搜「Kimi」；
3. **桌面端 Kimi Work**（3.1.0 及以上）：Windows 和苹果芯片 Mac，写文档、做 PPT、跑深度研究的主力；
4. **Kimi Code**：程序员用的编程助手，`/model` 命令切换到 Kimi K3.1 Pro；
5. **API**：platform.kimi.ai，标识符 `kimi-k3.1-pro`，另有 2~3 倍速的 `highspeed` 版。

注意一个细节：**K3.1 Pro 只支持思考模式**，关掉思考的请求会被拒绝——它默认就是「先想再答」的，不用你手动开。

## 免费还是付费：先看 App 里有没有，再决定掏不掏钱

这是大家最关心的。分两步走：

**第一步：免费版先看一眼。** 打开 Kimi App 或网页，在模型选择器里找有没有「Kimi K3.1 Pro」。有，就能直接免费用；没有，说明还在灰度或要会员——别急着掏钱，先往下看。

**第二步：会员档位（国内版价格，2026 年 10 月官网口径）。**

| 档位 | 月付 | 年付折算 | 跟 K3.1 Pro 的关系 |
|---|---|---|---|
| 免费 | ¥0 | — | 看灰度，先试 |
| Go | ¥49 | ¥39/月 | **不含** Kimi Code，想写代码别买这档 |
| Plus | ¥99 | ¥79/月 | **能用 K3.1 Pro**（Kimi Code 里需 Plus 及以上） |
| Pro | ¥199 | ¥159/月 | Highspeed 加速版 + 100 万完整上下文 |
| Max/Ultra | ¥699/¥1399 | — | 重度用户，普通人用不上 |

实话时间：Kimi 的会员额度是**共享池+只显示百分比**，不告诉你还剩多少 token。社区实测同一档位烧的速度能差十倍——变量是你的用法。所以建议：**免费先试出自己用量，再按需买 Plus；Pro 的加速和长上下文是真有需要再上。** 老用户注意：9 月改版后老套餐可原价续费，别手滑换成新套餐。

## 四个避坑点，看完再动手

1. **权重还没放出来。** 承诺 11 月 4 日前放权重，但**许可证还没公布**——想本地部署、想商用的，等许可证原文出来再动手，别听二手传言（M3.1 Flash 那篇我们吃过这个教训）。
2. **成绩单是官方自测。** 在独立评测出来前，所有「接近 Opus 5.5」的说法都先打个问号。
3. **企业版默认是关的。** 公司/团队用的 Kimi Enterprise，管理员要手动开启这个模型，不然你在里面找不到。
4. **API 和会员是两套账单。** 买了 Plus 会员 ≠ 有 API 额度；往 API 里充钱 ≠ 会员升级。开发走 API 看 token 价（$2/$10），普通用走 App 看会员档，别充错地方。

## 一句话总结

Kimi K3.1 Pro 是今年国产大模型里「效果」这条线最强的一次还击：3T 级 MoE、100 万上下文、编程金融双强项，价格还只有 Opus 5.5 一半；国内用户零门槛上手，免费先试、Plus 起步。权重 11 月 4 日前放出后，我会再跟一篇本地部署教程——到时候商用、自己搭服务的同学再看那篇。
