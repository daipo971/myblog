先说结论：智谱 11 月 23 日发布 GLM-5.4，这是第一个把 Loop Transformer 架构用在旗舰模型上的国产大模型。参数规模约 750B，与上一代旗舰 GLM-5.3 同级，但 28 层中间层每步前向跑两遍，官方说法是智能水平可比 2T–3T 参数的模型。视觉理解与 100 万 token 上下文同时补齐，Coding Plan 订阅用户当天就能用。但先别急着下判断：旗舰本身的基准分数一张没公布，API 与开源权重都还没上线，2T–3T 的说法目前只是厂商自报。本文把官方博客、技术细节与三家独立报道交叉核对过，数字后面都标了出处。

![插画：发光的神经网络层叠结构与循环光带，象征同一组模型层被重复使用、越跑越深](/images/glm-5-4-loop-transformer/cover.webp)

## 1. 发布了什么：规模没变，结构变了

GLM-5.4 是智谱 GLM-5 系列的第四款旗舰，也是该系列第一次换架构。关键参数先列出来：

| 项目 | GLM-5.4（官方博客，2026-11-23） |
| :--- | :--- |
| 参数规模 | 约 750B（GLM-5 基底） |
| 架构 | Loop Transformer：28 层循环跑两遍，权重共享 |
| 上下文 | 100 万 token |
| 视觉理解 | 新增，可读截图与图片 |
| 推理速度（官方说法） | 闲时最高 200 tokens/s，高峰 70–80 tokens/s |
| 上线渠道 | GLM Coding Plan、ZCode、Z.ai Chat、智谱清言 |
| API | 即将推出（Coming Soon），暂无价格与日期 |
| 开源权重 | 计划在完成安全加固后开源，暂无日期 |

和上一代比，最直观的变化有三点。第一，**参数没涨，深度涨了**：同样约 750B 的底子，28 层跑两遍，官方称智能水平可比 2T–3T 参数的模型——注意这是官方说法，旗舰基准表尚未公布，见第 3 节。第二，**旗舰第一次带上原生视觉**：能读截图与图片，定位是"看图写代码"，比如对着一张界面截图改前端、看报错截图定位问题。第三，**定位从"写代码"扩到"泛化编程"（Generalized Coding）**：官方演示用代码去生成视频、做完整游戏、做 3D 建模与机械设计，包括一段模型自述的 Hello World 音乐视频、FreeCAD 里建的六轴机械臂、一个带角色移动、物理、地图与战斗系统的完整游戏，以及纯数学几何加自定义 GLSL 着色器生成的交互式 3D 观鸟场景。这些都是官方演示的单点 showcase，证明链路能跑通，不等于在你的任务上也能一次跑通。

智谱在官方博客里还透露了下一步：正在探索自适应计算（难的 token 自动多循环几遍），以及循环次数与模型规模继续放大后的收益规律；下一款"显著更大"的模型会沿用这次的经验，"很快就绪"。也就是说，GLM-5.4 在智谱内部的定位是过渡一代旗舰，不是终点。

## 2. Loop Transformer 是什么：不加参数，把同一组层多跑一遍

标准 Transformer 里，每一层在一次前向里只跑一次；模型想更深，只能堆更多层、加更多参数。Loop Transformer 反过来：**同一组权重共享的层，在一次前向里跑多遍，每一遍用上一遍的隐藏状态继续精炼**。打个比方：普通模型是写完答案直接交卷，循环模型是写完再读一遍、改一遍再交——同一个脑子，没多长知识，但第二遍能纠掉第一遍的错。

这个想法本身不新，2018 年的 Universal Transformer 就提过权重共享的深度；近年小规模上的循环深度研究也有收益。但直接把现成大模型改成循环结构会遇到三个工程问题，智谱在 750B 规模上各给了一个解法：

- **逐 token 门控渐进更新（Gated Progressive Updates）。** 直接把中间层改成多遍循环，隐藏状态的激活范数会在迭代间越涨越大，下游层拿到的是超出预期分布的表示。GLM-5.4 给每次迭代加了独立的逐 token 门，控制候选更新写回残差流的比例：第一遍保守写、建全局上下文，第二遍再放开写、做精炼；难的 token 第一遍就写得更积极。
- **混合 KV 缓存（全局共享 + 独立滑动窗口）。** 天真的实现会给每次循环各存一份完整 KV 缓存，内存随循环次数翻倍。GLM-5.4 的做法是第二遍复用第一遍选出的稀疏 KV，只给新一遍单独留一个滑动窗口缓存，两股 KV 流可以在同一位置重叠。结果是多一遍循环只多一个滑动窗口的缓存成本，100 万上下文的部署成本增加可控。
- **稀疏注意力索引复用。** GLM-5 基底本身用稀疏注意力，第二遍直接复用第一遍索引器生成的注意力索引，不产生额外索引开销，官方称效果与每遍重算基本一致。

还有一个关键选择：**不是从头训练，而是"改装"**。智谱称，从头训练的循环模型在同等预训练算力下仍落后于非共享结构，所以他们拿已经预训练好的 GLM-5 基底，通过继续训练把它转成 Loop Transformer，用相对较小的算力抬高了智能上限。改装前，循环架构在 1B、4B、30B、750B 四个规模上逐级验证过，官方称这是在检验"扩展正确性"：架构改动在小规模上成立，不等于在大规模上也成立。

## 3. 横向比：先看清哪些数字能信、哪些不能

先把 GLM-5.4 放进同一张表里，再逐行讲哪些数字可信：

| 模型 | 参数（总/激活） | 上下文 | 架构特点 | API 状态 | 权重 |
| :--- | :---: | :---: | :---: | :---: | :---: |
| **GLM-5.4（智谱，11-23）** | **约 750B** | **1M** | **Loop Transformer，28 层跑两遍** | **未上线** | **计划开源，无日期** |
| GLM-5.3（智谱，08-14） | 744B / 40B | 以官方模型卡为准 | 标准 Transformer | 已上线，$1.40 / $4.40 | MIT 开源 |
| Qwen4-Max（阿里，11-16） | 2.4T / 71B | 1M | 稀疏 MoE + 稀疏注意力 | 已上线，$1.50 / $4.50 | 闭源 |
| Inkling 2 Mini（Thinking Machines，11-20） | 26B / 3.4B | 未公布 | Loop Transformer，开源权重 | 未公布 | 已开源 |

（GLM-5.3 参数与价格见本站 [智谱 GLM 模型档案](/posts/glm-guide/)；Qwen4-Max 见 [Qwen4-Max 正式上线](/posts/qwen4-max-launch/)。）

这张表最值得说的不是参数，而是**三组数字的可信度完全不同**：

**能信的：架构、规模、渠道。** 28 层跑两遍、约 750B、100 万上下文、视觉理解、Coding Plan 已上线，这些是官方博客原文与 TechNode、Decrypt 三方一致的事实。速度 200 tokens/s（闲时）、70–80 tokens/s（高峰）是官方说法，独立验证尚未出现。

**半信的：30B 对照实验的分数。** 官方博客公布的唯一一张量化表，比较的是两个同参数 30B 小模型（200K 长上下文微调后、思考模式开启）：循环版 AIME25 从 19.17 升到 30.42，GPQA-Diamond 从 47.58 升到 56.26，MMLU-Pro 从 71.65 升到 75.05，IFBench 从 50.20 升到 53.47，多数基准的输出还缩短了 10–14%。方向是积极的——循环结构在小模型上确实有效、且推理从显式输出 token 转向了隐式的循环深度。但必须写清：**这是 30B 小模型的对照实验，不是 750B 旗舰的分数**，30B 的基线本身远低于前沿水平，不能用它证明旗舰可比 2T–3T。

**不能直接信的："可比 2T–3T 参数模型"。** 官方博客没有给出旗舰与 GLM-5.3、或与 Qwen4-Max 等同级旗舰的逐项基准对照。独立评测方也暂时无法验证：Artificial Analysis、LMArena 这类机构要测它，首先需要 API，而 API 还没上线。等 API 上线、独立分数出来之前，这句话只能按厂商自报处理。

还有一个同行对照值得注意：Thinking Machines 11 月 20 日发布的 Inkling 2 Mini 同样是 Loop Transformer，却是另一端——26B 参数、3.4B 激活、开源权重、主打笔记本本地运行。11 月是循环架构集中落地的一个月：750B 的闭源旗舰与 26B 的开源小模型同时押注"同一组层多跑几遍"。谁的路线更划算，要等两边的独立分数与真实部署成本都出来才见分晓。

## 4. 现在怎么用：只有订阅渠道，API 还没来

普通人今天能用上 GLM-5.4 的路径只有一条：**订阅 GLM Coding Plan**。据 Decrypt 报道，档位是 Lite $18/月、Pro $80/月、Max $168/月；TechNode 报道称 V2、V3 与团队版订阅用户的 GLM-5.4 用量额度比 GLM-5.3 多 50%。入口在 ZCode、Z.ai Chat 与智谱清言里，模型名在 Claude Code 里是 `glm-5.4[1m]`，其他工具里是 `glm-5.4`。

三条具体建议：

1. **已有 Coding Plan 订阅的用户，今天就能换。** 在模型选择器里切到 glm-5.4，先拿一个真实长任务试：比如多文件改代码、或对着截图改界面。重点感受两点——视觉理解是不是真能读懂你的截图，以及长任务会不会陷入官方自述的"马拉松式思考"。
2. **只想调 API 的用户，先别动。** API 标注 Coming Soon，没有价格、没有日期，也没有第三方渠道。任何现在就卖"GLM-5.4 API 额度"的第三方，都与官方口径对不上。
3. **想本地部署的，等权重消息。** 官方说法是"完成必要安全加固后负责任地开源权重"，没有日期。部署规划别按这个排期，等官宣再说。等不及的可以先看本站的 [中国大模型 API 价格表](/posts/china-llm-api-pricing/)，对照已上线模型的输入输出价算账。

## 5. 三个提醒：下单之前先看完

### ⚠️ 提醒 1：别把 30B 的实验分数当成旗舰分数

官方博客的量化表是 30B 小模型的对照实验，旗舰 GLM-5.4 本身没有逐项基准。任何"GLM-5.4 跑分超过某某"的说法，在独立分数出来之前都不可信。等 Artificial Analysis 与 LMArena 收录后再看。

### ⚠️ 提醒 2：马拉松式思考可能让长任务更慢、更贵

官方自己承认的短板：模型有时会陷入超长的"马拉松式思考"循环，官方称这种 prolonged reflection 与自我纠正"持续提升准确率"。对用户来说，准确率提升的另一面是等待时间与 token 消耗都可能变长——Coding Plan 是周配额制，额度比 5.3 多 50%，但长思考任务会更快烧掉额度。先用真实任务小规模试，再决定是否把主力任务切过来。

### ⚠️ 提醒 3：别和 GLM-5.3、GLM-5.3-Flash 搞混

5.3 仍是已上线、有 API、有 MIT 开源权重的旗舰，API 价 $1.40/$4.40 每百万 token；5.3-Flash 是 320B 的轻量多模态版，价格约旗舰十分之一。5.4 目前只有订阅渠道、没有 API、没有权重。三者的价格、渠道与开源状态完全不同，选型时按这张表对，别只看版本号。

## 6. 总结

GLM-5.4 是智谱一次明确的路线表态：不再只堆参数，改堆"同一组层多跑几遍"的计算深度。750B 参数、28 层循环、视觉理解与 100 万上下文，配上 Coding Plan 当天可用，对订阅用户来说是马上能试的新东西；但旗舰无基准、API 未上线、权重无日期，2T–3T 的说法也还只是官方口径。值得跟的三件事：API 何时上线与定价、Artificial Analysis 与 LMArena 的独立分数、开源权重的具体时间。任何一项落地，都值得再写一篇跟进。
