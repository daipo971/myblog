腾讯混元今天发布 Hy4 正式版。相比 8 月 28 日开源的 Hy4 preview，正式版扩展了预训练和后训练规模，**首次引入视觉理解、首次支持操作电脑**，指令遵循、长文理解、长程任务和深度研究能力全面提升。模型已经在元宝、ima、CodeBuddy / WorkBuddy 和腾讯云 TokenHub 上线，国内可直接用，不用翻墙、不用海外账号。但有一点先说清：**权重今天还不能下载，官方只说「近期开源」**。

## 规格：还是 770B 和 1M 上下文，补上了眼睛

Hy4 沿用 preview 的底座：总参数 770B、每 token 激活 49B 的 MoE 架构，上下文窗口 1M（腾讯云 TokenHub 官方文档标注最大输入 960k、最大输出 64k）。真正的变化在能力清单上——TokenHub 的官方模型列表里，Hy4 的能力支持比 preview 多出一项「图片理解」，这正是正式版最核心的升级：

- **细粒度图像处理与复杂图表分析**：看懂截图、报表和图表，而不只是读文字。
- **数学视觉推理**：处理带图的数学问题，把感知、深度推理和工具调用串起来完成。
- **长文与长程更稳**：官方称指令遵循、长文理解、长程 Agent、深度研究四项能力大幅提升；自建测试中幻觉率从 preview 的 15.76% 降至 5.45%（官方自报数据）。

## 首次支持电脑操作：命令行和图形界面一起用

这是正式版的另一个「从 0 到 1」：Hy4 可以灵活结合命令行（CLI）和图形界面（GUI）操作电脑，并针对 Blender、CAD 等专业软件和跨应用长程任务做了专项训练。换句话说，它不只是回答问题，而是能像 [AI Agent 完全指南](/posts/ai-agent-complete-guide-2026/) 里讲的那样，自己动手把多步骤任务一步步做完——这也是腾讯给 Hy4 的定位：为真实生产力准备的长程 Agent 基座。

落地上，腾讯云 ADP（智能体开发平台）已首发接入 Hy4；腾讯金融科技联合组织的众测里，213 位专家（其中 153 位来自外部头部金融机构）对 579 个真实金融任务盲评，Hy4 以 3.04 分拿到开源模型第一。办公场景还支持「人机双写」，用户与模型实时协作编辑 Word、Excel、PPT。

## 跑分怎么读：官方自报，且官方自己留了余地

腾讯的官方说法是：Hy 首次「跻身最强开源模型之列」，金融众测开源第一，GameDev、GameLogic 两项评测分别提升 19.1% 和 9.8%。读这些数字要注意两点口径：

- 以上全部是**腾讯官方公布的数据，未经独立第三方验证**；
- 腾讯自己也明确承认，Hy4 与顶尖闭源模型之间仍有较大差距。

所以正确的读法是：它自报进入了开源第一梯队，但「最强开源」是官方定位，不是第三方结论，等实际 API 用户反馈和第三方榜单出来再下判断不迟。同梯队的国产旗舰可以对照看 [智谱 GLM 模型档案](/posts/glm-guide/) 和 [通义千问 Qwen 模型档案](/posts/qwen-guide/)。

## 价格和入口：与 preview 同价，TokenHub 五折到年底

- **API 价格不变**：腾讯云 TokenHub 官方价格页（2026-11-04 更新）显示，Hy4 与 preview 同价——输入 6 元、输出 18 元、缓存命中 0.3 元（每百万 tokens）；即日起至 2026 年 12 月 31 日，TokenHub 上按刊例价 5 折计费。API 还同步接入了 OpenRouter、Hermes、OpenCode 等平台。
- **免费体验入口**：元宝、ima 打开就能对话用；写代码走 CodeBuddy / WorkBuddy，据官方发布信息，11 月 4 日至 15 日提供一定额度免费使用；企业微信智能助理「大圆」也已上线。
- 所有入口都在国内，普通用户今天就能上手，不需要海外账号和支付方式。

## 两个「近期」，别看错时间

- **权重只是「近期开源」**：preview 的权重 8 月已经开源（Apache 2.0），但正式版的权重和系统卡片（System Card）要等后续随开源一并发布。截至发稿，腾讯混元的 GitHub 组织下仍只有 Hy4 preview 的仓库。今天看到「Hy4 开源下载」类标题，先确认下的是哪个版本。
- **Hy4 Flash 也只是「近期发布」**：更便宜的轻量版在路上，还没上线，不要把 preview 的价格和规格套到它头上。

和昨天美团的 [LongCat-2.5](/posts/longcat-2-5-launch/) 一样，这又是一个「在线服务和 API 先行、权重随后跟上」的国产旗舰发布。权重落地后，本站会更新这篇并补上许可证与本地部署信息。更多国产模型按家族整理，见 [中国与开源模型](/categories/中国与开源模型/) 中心页。
