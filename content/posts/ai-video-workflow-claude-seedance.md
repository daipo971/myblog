做 AI 视频最烧钱的环节，不是生成本身，是**抽卡**：一句话丢给视频模型，出来不对，改两个字再抽一次，一条几秒的片子按秒付费，钱包就是这么空的。2026 年 11 月 5 日晚，作者 Eian 在 X 发了一篇长文（1.9 万浏览），讲他用 Claude Code + Codex + Seedance 做完整短片的全流程，核心不是某个模型多强，而是一套**把错误挡在花钱之前**的工作纪律。本文把这套方法拆开讲清，附可以直接套用的提示词结构和检查清单。

![电影片场风格插画：机器人导演拿着场记板，旁边是画着分镜首尾帧的画架和一卷胶片](/images/ai-video-workflow-claude-seedance/cover.webp)

## 先看分工：人只当老板，三个 AI 各干一段

这套工作流最值得学的不是工具，是分工。人全程只做四件事：选方向、确认画风、批准花钱、看成片。其余全部分出去：

| 角色 | 工具 | 干什么 |
| --- | --- | --- |
| 导演 | Claude Code | 写故事与分镜、写全部提示词、检查每张图和每段视频、用 ffmpeg 和 Python 做后期拼接、调色、放大 |
| 画师 | Codex | 画角色设定图、样帧，以及每个镜头的**首帧和尾帧**图片 |
| 动画师 | Seedance（火山引擎 API） | 把首尾帧变成几秒钟的视频片段 |
| 老板 | 你 | 定方向、批画风、批预算、验收 |

接入方式不复杂：Claude Code 和 Codex 装在同一台电脑上，导演可以直接调用画师出图；Seedance 去火山引擎注册、申请 API Key（放在环境变量里），由导演写脚本调用。为什么要这么分？因为三个环节的**改错成本完全不同**，这就引出全篇最重要的一条原则。

## 核心原则：三道关，把错误挡在花钱之前

作者的原话逻辑是：改提示词只要动几个字、几乎不花钱；重画一张图花的是图片额度；**重新生成视频是按秒真金白银**。所以纪律只有一条：

> 文字里能发现的错，不要留到图上；图上能发现的错，不要留到视频上。

后面所有步骤——先审故事、再审分镜、首尾帧逐项检查、提交前再开一个 agent 复核——全是这条原则的展开。记住这一条，下面就都是操作细节了。

## 全流程八步

**第一步，先把故事聊定稿。** 把初步想法讲给导演，一起打磨。判断标准很实在：每个转折能追问出「为什么、东西从哪来」；主旨能一句话说清，说不清就是剧情太平；开头就放最抓人的画面；旁人的反应要像真人，有先后、有身体反应。还有一条避坑：剧情要挑 AI 拍得出来的，人物交叉、手拿小物件、镜子倒影、一镜内换光、一人连做三个动作，都是视频模型的弱项，能避就避。结构上首选「片段式」（每个镜头不用接戏），最稳。

定稿前有个小技巧：**另开一个全新的 agent 只审故事**，不给它任何其他文件。主导演跟你聊了很久会自动脑补，新 agent 像第一次看片的观众，它看不懂的地方，就是真没讲清楚的地方。

**第二步，分镜。** 作者认为这步甚至比剧情更重要。每个镜头写清：景别、机位、运镜、谁往画面哪边走（写左右）、靠什么表情推进、什么东西在动、怎么转到下一镜。几条硬规则：每镜换角度，平视正面全片最多两次；画面里要一直有东西在动；构图别把人放正中间，眼睛落在画面横向约 38% 或 62% 处更耐看；配色在画第一张图之前就定成色表，再把画面转成黑白检查明暗对比——黑白下人和背景分不开，彩色也救不回来。

**第三步，定画风、画设定图。** 画风一句话说清（手绘、剪纸、写实……），有参考图直接发。定完给每个角色画设定图：正面、侧面、几个表情，身上的固定物写死位置（比如纹身在左手臂），不然后面每张图位置都会漂。

**第四步，逐镜头画首尾帧——全篇最关键的一步。** 首帧是镜头第一张画面，尾帧是最后一张。只靠文字生视频容易出逻辑错误，小物件（雨、帽子、纹身）只写在文字里，拍着拍着就会消失；首尾帧都画上，模型才有锚点。顺序也有讲究：先写清每镜首帧画什么、尾帧画什么、中间发生什么，审过再画；先画内容最多的尾帧，再在尾帧上改出首帧，保证机位和构图一致；运镜是慢慢推近时，尾帧可以把首帧裁一块放大——首尾构图完全一样，等于镜头根本没动。

**第五步，写视频提示词，并提交前审核。** 提示词写法见下一节。写完不是直接提交：另开一个审核 agent，把提示词和首尾帧逐项核对，明确写「通过」才许提交。作者说这一步查出过很多真金白银的坑：两张图里杯子大小差了 13%、帽檐一张有一张没有、左右写反了。

**第六步，生成。** 省钱要点：先用 720p 生成，后期再放大到 1080p；不用专门拍测试片，直接拿第一个正式镜头试，能用就赚了；新方法先拿一两个最难的镜头验证，行得通再全量提交。片段出问题别马上重拍：先看能不能剪掉（问题只在开头结尾几帧）、能不能用代码修，实在要重拍，先改提示词或首尾帧，原样重拍大概率还是错的。旧片段别删，新拍的不一定更好，最后一起挑。

**第七步，后期全用代码做。** 拼接、转场、调色、放大都让导演写程序完成：调色只动饱和度和亮度、不动色相，保护肤色；720p 用 lanczos 放大到 1080p 加轻微锐化，不用整段插帧；配乐卡点只从原曲上量拍点。

**第八步，全片复核。** 再开一个新 agent，只给成片、不给任何结论，让它像观众一样从头看：先写它看懂的故事，再列看不懂的地方，逐镜查穿帮、道具数量、颜色跳变、脸变形，最后老实写明它查不了的东西（动态手感、声音）。做完把画风、提示词、犯过的错写成总结存档，下次做片直接复用。

## 视频提示词：固定用七段式

作者强烈推荐把每个镜头的提示词写成固定的七段，把每一秒发生什么都写死。本站按其结构整理如下：

1. **画风**：一句话，如「干净的现代 2D 手绘动画，平涂色块，线条利落」，与首尾帧完全一致。
2. **镜头**：总时长、景别、机位、运镜；不动就明说「不推不拉不摇，不切镜」。
3. **构图与配色**：人和物在画面哪里、墙和光是什么颜色，与首帧对齐。
4. **人物**：每个人的长相、衣服、固定道具，写死。
5. **逐秒**：开头 0.2 秒与首帧完全一致，逐段写谁做什么、表情怎么变、手放哪、不能碰什么、往画面哪边动；最后 0.3 秒全部停住，与尾帧完全一致。
6. **声音**：只写看得见来源的声音，人物不说话就写明。
7. **约束**：画面里始终只有首帧里的人和物，脸和身形全程不变，一镜到底，无文字、无字幕、无水印。

配套的经验对照，挑最常见的几条：

- 一群人同时做同一个动作会很假 → 写清先后顺序，谁先、隔一两秒谁再动，首帧也别摆同一姿势。
- 方向写反 → 方向一律按画面写，「朝画面左边走」，不写东南西北。
- 东西凭空出现或数量变化 → 只用首帧里已有的东西，数量直接写进提示词。
- 写「不要怎样」经常没用 → 尽量改成正面说法，把「有什么」写清，而不是罗列「没有什么」。
- 一个镜头动作太多必乱 → 每镜只写一两个主要动作。

## 首尾帧检查清单（提交前逐项过）

1. 后面要用到的东西，首帧里必须已经出现，否则会凭空冒出来。
2. 需要拍到别人反应的，首帧就把人摆好位置、脸朝向镜头——一个镜头中途切不过去。
3. 多人同框不摆同一姿势，否则模型会让所有人同时动。
4. 给动作留空间：东西要落到的地方先空出来，头顶留空。
5. 风向统一：围巾往左飘，床单就不能往右飘。
6. 缩小到手机大小看一遍：远处的人太小、看不清就改构图。
7. 放大找多余物件：多出来的水壶、奇怪的细线都要清掉。
8. 首尾帧叠在一起看：不该变的地方必须严丝合缝，墙色变了视频里墙就会慢慢变色，杯子大一点视频里杯子就会慢慢变大。

还有一条改图纪律：生图工具改一小块也会把整张图重新处理，所以局部修改要把改好的那块贴回原图，别整张替换。

## 成本账（作者口径）

- Seedance 走火山引擎 API：作者用的两个型号，720p 约 ¥1.5/秒（2.5）和约 ¥0.5/秒（2.0 mini），实际以账单为准。他的经验是：不是特别复杂的镜头，2.0 mini 就够用，价格只有约三分之一。
- 720p 生成 + 后期放大到 1080p，是全程的基本盘，别一上来就用高分辨率烧钱。
- 声音要听过再用：2.0 mini 自带音效经常能直接用；2.5 即便写了「没有音乐」有时也会混进音乐，这种片段的自带声就别用，音效后期另加。
- 注意（本站补充）：以上价格与型号为作者 2026 年 11 月的实测口径，火山引擎的价格和模型版本会变，动手前去官方文档核对一遍。作者还有一个进阶玩法：开四个 agent 分工（主做、审核、监督、按偏好在预算内拍板的代理），适合熟练之后再上，新手先把单线程流程跑通。

## 常见问题

**没有 Claude Code 和 Codex，能照着做吗？**
能学方法、要换工具。这套流程的骨架是「文本审 → 图审 → 视频审」三道关和首尾帧锚点，跟具体工具无关：导演可以换成任何能写脚本的编程 Agent，画师可以换成任何生图工具，动画师可以换成即梦网页版手动提交（Seedance 本来就是字节自家的模型，即梦是它的消费级入口，本站此前介绍过，见 [Seedance 在即梦一直能用](/posts/2026-10-14-seedance/)）。手工版慢一些，但纪律照搬，抽卡率一样能降。

**国内能直接跑全套吗？**
分开看：Seedance 是字节的模型，火山引擎国内可正常注册使用；Claude Code 与 Codex 是海外服务，需要你平时使用它们的网络与账号条件。只用国内工具拼一个等效版本（国产编程 Agent + 国产生图 + 即梦），流程同样成立。

**这套方法适合做什么片子？**
最适合几秒一个镜头、镜头之间弱衔接的片段式短片：广告、产品演示、短剧单镜头、科普动画。要做长镜头一镜到底、强连续剧情的，先降低预期——连贯式是所有环节里最容易穿帮的结构。只想做几秒的循环小动图，连这套流程都不用上，[ChatGPT 直接生成 GIF](/posts/chatgpt-gif-guide/) 就够了；想系统比较视频模型本身，看 [AI 视频生成横评](/posts/ai-video-generation-comparison-2026/)。
