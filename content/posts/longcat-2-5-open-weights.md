先说结论：**美团 11 月 10 日按 MIT 协议开源了 LongCat-2.5 的权重——1.6 万亿参数、每 token 激活约 48B，终端编码榜 88.4 分，离 Claude Opus 5 只差 0.7 分**。但先别急着下载：BF16 权重大约 3.56TB、208 个文件，美团官方给出的 NPU 部署示例是 194 块华为昇腾 Atlas A2。对绝大多数人，能马上用的不是权重本身，而是两条更现实的路：OpenCode 限时免费两周（每天 100 次请求），以及官方 API 的限时价（输入 ¥2、输出 ¥8 每百万 token）。本文讲清三件事：这模型到底强在哪、和 Opus 5、DeepSeek 比处在什么位置、普通人三条上手路径各有什么坑。

## 1. 核心底层逻辑与原理解析

LongCat-2.5 是美团面向长程智能体任务的原生多模态 MoE 模型，11 月 2 日先以 API 发布，11 月 10 日开源权重。理解它抓住三个数就够了：1.6 万亿、48B、1M。

**1.6 万亿是总参数，48B 是每次激活的。** MoE（混合专家）的办法是把模型拆成大量专家，每个 token 只路由给其中几个专家处理。所以推理时真正干活的只有约 48B 参数，成本不像 1.6T 听起来那么吓人——但权重本身还是要存下来，3.56TB 的磁盘和加载它的显存一分都省不掉。这是理解后面所有"能不能跑"的关键。

```
输入 token ──▶ 路由器 ──▶ 专家 A（激活）
                          ├─▶ 专家 B（激活）
                          └─▶ 专家 C（激活）
其余数百个专家待命，不参与本次计算
总参数 1.6T，单次激活约 48B
```

**原生多模态，不是外挂视觉模块。** 模型把原生分辨率的视觉特征转成离散 token，和文本放在同一个语义空间里联合对齐。所以它能直接看图、看视频、做 3D 任务和视觉编程，而不是先由别的模型把图转成文字再推理。

**长程 agent 是它的主战场。** 训练上用了真实工程任务、可复现的 agent 失败样本和防奖励作弊的手段，目标是把一个长流程端到端做完——复杂代码库开发、完整项目构建、创意设计、3D 任务，而不是一问一答。多教师学习（agent、推理、交互三个老师）用全词表 KL 蒸馏和 Tree Attention 带它做多轮执行、推理、指令遵循与安全。

**W4A4 量化是为国产加速器准备的。** 模型卡写明，LongCat-2.5 对专家权重与激活做 W4A4 量化，用 FlatQuant 风格的可学习变换实现原生 INT4 计算，精度与未量化版本在已测基准上接近。在线压测对比 W8A8 基线：prefill 吞吐高 43.3%、decode 吞吐高 42.77%、首 token 延迟低 15.91%、每 token 输出时间低 19.72%；再叠加 KV 缓存量化，W4A4KV8 的 decode 吞吐比 W8A8KV16 高 92%。这套东西明确面向国产 AI 加速器，部署走美团的 SGLang-FluentLLM 项目 NPU 分支。

**上下文与思考模式。** 上下文 1M、API 最大输出 128K，支持思考模式开与关：开着保留完整推理内容，效果更好；关掉更省 token。模型卡的用法示例就是用 OpenAI 兼容接口调它，`enable_thinking` 与 `save_history_reasoning_content` 两个开关控制思考。

## 2. 核心方案与多维对比横评

先放模型卡的基准表（分数带 * 的引自公开技术报告或榜单，不带 * 的是美团内部实测、仅供参考）：

| 模型 | Terminal Bench v2.1 | Terminal Bench v4.0 | DeepSWE v1.1 | PaperBench | BrowseComp |
| :--- | :---: | :---: | :---: | :---: | :---: |
| **LongCat-2.5** | **88.4** | **38.5** | **64.6** | **82.1** | **91.9** |
| Claude Opus 5 | 89.1* | 53.9* | 68.8* | 79.1 | 90.8* |
| GPT-5.6-Sol | 88.8* | 37.3* | 72.7* | 83.3 | 90.4* |
| DeepSeek-V4.1-Flash | 90.6* | 31.2* | 74.2* | 77.5 | 91.5 |
| GLM-5.3 | 88.2* | 41.8* | 66.9* | 73.7 | 81.0 |
| kimi-k3 | 88.3* | 12.6* | 67.5* | 77.5 | 91.2* |

怎么读这张表：

- **Terminal Bench v2.1 上确实贴身。** LongCat 88.4 分，Opus 5 是 89.1，只差 0.7；GPT-5.6-Sol 88.8、GLM-5.3 88.2、kimi-k3 88.3 全挤在同一档，国产模型在这个榜上已经和海外旗舰贴身肉搏。但别只报这一行：DeepSeek-V4.1-Flash 是 90.6，比 LongCat 还高 2.2 分；智东西的对照也指出，26 项可比测试里 DeepSeek 有 14 项高于 LongCat。"国产第一"别乱写。
- **新版基准 v4.0 差距拉开。** LongCat 只有 38.5，Opus 5 是 53.9，GLM-5.3 也有 41.8。v4.0 的任务更新更难，LongCat 的相对位置明显弱于 v2.1。只拿 v2.1 说事，就是挑榜。
- **DeepSWE 上也落后。** LongCat 64.6，Opus 5 是 68.8，GPT-5.6-Sol 72.7，DeepSeek-V4.1-Flash 74.2。PaperBench 82.1 仅次于 GPT-5.6-Sol 的 83.3；BrowseComp 91.9 倒是表中最高。
- **真正的卖点在许可与价格，不在单项榜首。** MIT 协议，可商用推理部署与二次训练，无需额外授权；API 限时价输入 ¥2、输出 ¥8 每百万 token（缓存命中 ¥0.04），美元标价对应 $0.30/$0.006/$1.20，远低于海外旗舰的 API 价。组合起来看，LongCat-2.5 的定位是"开源阵营里长程 agent 任务最能打的模型之一"，而不是"全面超越 Opus 5"。

## 3. 手把手完整实战流程

普通人三条路，按门槛从低到高：

### 步骤一：先免费试——OpenCode 限时免费两周

开源当天，OpenCode 宣布 LongCat-2.5 在平台限时免费两周，每天限 100 次请求，支持多模态与百万 token 上下文。截至 11 月 10 日中午，OpenCode 公开数据：累计 token 用量约 1090 亿，独立用户约 4700 名，已完成约 5 万次会话。两周从 11 月 9 日前后算，窗口到 11 月 23 日左右。做法就是在 OpenCode 里选 LongCat-2.5 模型，在免费额度内直接用——先拿它写一段真实代码、跑一个多步骤任务，比看榜单更能判断合不合你的手感。

### 步骤二：走官方 API 限时价

流程是注册 → 建 Key → 大陆用户实名 → 充值 → 按量调用 LongCat-2.5。API 兼容 OpenAI 与 Anthropic 两种格式，可以接进 Claude Code、Codex、Hermes 这类 agent 工具。模型卡给的用法是 OpenAI 兼容接口，思考模式用两个开关控制：

```python
response = client.chat.completions.create(
    model="LongCat-2.5",
    messages=messages,
    extra_body={
        "chat_template_kwargs": {
            "enable_thinking": True,
            "save_history_reasoning_content": True,
        }
    },
)
```

价格再算一遍：未命中缓存的输入 ¥2、命中缓存 ¥0.04、输出 ¥8，每百万 token。写一个 10 万 token 输入、2 万 token 输出的长任务，输入 0.2 元、输出 0.16 元，一共不到 4 毛钱——这是限时价的算法，正式价以平台实时账单为准，别写进长期预算。

### 步骤三：自己部署权重（给有集群的人）

仓库在 Hugging Face：`meituan-longcat/LongCat-2.5`（BF16，208 个文件，约 3.56TB），另有 W4A4 量化版 `meituan-longcat/LongCat-2.5-W4A4`（约 1.34TB）。国内下载走魔搭社区同名仓库。NPU 部署看美团的 SGLang-FluentLLM 项目（longcat-2.5-npu 分支）。官方示例配置是 194 块华为昇腾 Atlas A2：2 块做图像处理、64 块接提示词、128 块做生成。算一笔账：3.56TB 只是权重文件的磁盘占用，加载、KV 缓存与运行时开销另算；个人电脑与单卡工作站不用考虑满血版，W4A4 版也要 1.34TB 权重加集群级显存。

## 4. 工业级避坑守则

### ⚠️ 避坑点 1：别把"权重开源"理解成"本地能跑"
BF16 约 3.56TB、示例部署 194 块国产加速器；W4A4 约 1.34TB 也要集群级显存。个人用户先走 OpenCode 免费与 API，别一上来就下载权重占磁盘。本地部署的完整判断见文末站内教程。

### ⚠️ 避坑点 2：别只拿 Terminal-Bench v2.1 的 88.4 说事
v4.0 只有 38.5（Opus 5 是 53.9），DeepSWE 64.6 也低于 Opus 5 和 DeepSeek-V4.1-Flash；26 项对照里 DeepSeek 有 14 项更高。写"接近 Opus 5"要限定在 v2.1 这个榜上，写"超越"就是错的。

### ⚠️ 避坑点 3："全程国产硬件、零 NVIDIA 训练"是二次报道的说法
模型卡原文只说"在国产 AI 加速器上做基础设施优化"、W4A4 面向国产加速器；训练硬件构成未见美团官方原文直接表述。The Decoder 等二次报道称其训练用了国产硬件，写稿时标明来源，别写成官方口径。

### ⚠️ 避坑点 4：API 限时价没有官方截止日
输入 ¥2、输出 ¥8、缓存命中 ¥0.04 是限时优惠，官方没公布截止日；OpenCode 免费两周到 11 月 23 日左右。按限时价算长期成本会算错，正式预算以平台实时账单为准。

### ⚠️ 避坑点 5：参数口径有个小出入
美团宣称 1.6 万亿，HF 元数据显示 1.8 万亿，差额很可能来自嵌入表（模型卡没有把它计入）。引用参数时写"美团宣称 1.6 万亿"，别把两个数字混着用。

### ⚠️ 避坑点 6：开放的是权重，不是全部
训练数据与完整训练流程没有公布，官方指向的代码主要是部署用的；MIT 许可覆盖权重，不授予美团商标与专利权利。二次训练可以，拿它去声称是自己从头训的模型不行。

## 5. 总结与后续行动建议

一句话结论：LongCat-2.5 是目前开源阵营里长程 agent 任务最能打的模型之一，MIT 许可加便宜 API 是真利好；但 3.56TB 权重与 194 卡的示例配置说明，它首先是给有集群的团队和 API 用户准备的，不是给个人电脑的。

行动路径就三步：今天先去 OpenCode 免费用（窗口到 11 月 23 日左右）→ 觉得好用再开官方 API 限时价 → 有集群再考虑按 SGLang-FluentLLM 的 NPU 说明下载权重部署。11 月 25 日 Qwen4-Max 预览下线、Hy4 正式版权重仍未落地，这一周国产开源的动静不少，LongCat 这篇先写到这里，后续有部署实测再补。
