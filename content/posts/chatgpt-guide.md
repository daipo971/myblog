## 現在聊天框裡是哪個模型

選單上只寫「GPT-6」，背後依方案不同而不同。對照 OpenAI 幫助中心的模型說明文章，現況如下：

| 方案 | 聊天框預設 | 更高思考檔位 |
| --- | --- | --- |
| 免費 | Luna 檔模型 | 不含 |
| Go | Luna 檔模型 | 不含 |
| Plus | GPT-6（GPT-6 Sol 驅動，Instant 至 High） | 不含 Extra High 與 Pro |
| Pro 100／200／500 | GPT-6（GPT-6 Sol 驅動） | GPT-6 Pro（GPT-6 Astra 驅動） |
| Business、Enterprise | GPT-6，依工作區設定 | GPT-6 Pro，依工作區權限 |

有兩點容易搞混，先說清楚：

- **免費與 Go 用的 Luna，版本號在官方頁面說法不一。** OpenAI 的發布公告稱免費與 Go 用 GPT-6 Luna，但幫助中心的模型文章仍寫 GPT-5.6 Luna。兩邊都是官方頁面，本文如實寫「Luna 檔」，不替官方下定論。
- **GPT-6.1 Sol 與 GPT-6.1 Terra 不在聊天框。** 這兩個只出現在 ChatGPT Work 與 Codex 的模型選單裡，普通對話用不到。Plus 方案可以在 Work 與 Codex 裡用到 Astra，聊天框裡則沒有 Pro 檔位。
- **GPT-5.6 Sol 仍可選。** 付費方案的選單裡保留 GPT-5.6 Sol，適合習慣舊模型輸出風格的人，不必強行換新。

## 價格：各檔對照

以下為 OpenAI 官方定價頁的美元標價（查閱時間 2026-11-10，稅前；各地結帳金額可能不同，以結帳頁為準）：

| 方案 | 月費（美元） | 計費方式 | 廣告 | 適合誰 |
| --- | --- | --- | --- | --- |
| 免費 | 0 | — | 可能有 | 偶爾問問題、試水溫 |
| Go | 8 | 僅月付 | 可能含廣告 | 輕度日常使用、預算優先 |
| Plus | 20 | 僅月付 | 無 | 每天用的個人主力 |
| Pro 100 | 100 | 僅月付 | 無 | 重度個人用戶 |
| Pro 200 | 200 | 僅月付 | 無 | 幾乎天天高強度使用 |
| Pro 500 | 500 | 僅月付 | 無 | 最高用量，另含 Ultrafast |
| Business | 20（年付）／25（月付） | 按人頭，至少 2 席 | 無 | 小團隊 |
| Enterprise | 洽詢 | 按合約 | 無 | 大公司、學校 |

付費前先看清這幾條（均來自 OpenAI 官方頁面與幫助中心）：

- **個人付費方案只有月付。** Go、Plus、Pro 三檔都不提供年付或一次付多個月，Pro 幫助文章明寫這一點。
- **Pro 三檔每月附等額 API 額度。** Pro 100 附 100 美元、Pro 200 附 200 美元、Pro 500 附 500 美元的 API 額度，隨計費週期到期，不累積。Plus 沒有 API 額度，API 用量另計。
- **Pro 沒有 5 小時用量窗口，Plus 有。** Plus 在 Work 與 Codex 有 5 小時用量窗口（例如 5 至 45 條 GPT-6 Astra 訊息，依任務而定）；Pro 三檔目前沒有這個限制。
- **Ultrafast 只有 Pro 500 有。** 更低延遲的 GPT-6 Astra 與 GPT-6.1 Sol 回應是 Pro 500 獨佔，Pro 100、Pro 200、Plus、Business 都沒有。
- **用量額度即將跨產品共用。** OpenAI 幫助中心提到，自 12 月起，Plus、Pro、Business 方案的用量額度將在 ChatGPT 與 Codex 之間共用、以 token 計；即時對話不扣額度。細則以官方後續公告為準。
- **API 價格另計。** 模型 API 輸入／輸出價（每百萬 token）：GPT-6.1 Sol 約 2／10 美元、GPT-6 Astra 約 10／50 美元、GPT-6.1 Terra 約 1／5 美元。API 與 ChatGPT 訂閱是兩套帳，訂閱費不抵 API 費（Pro 附的額度除外）。

## 免費版夠不夠用？該不該付費

先給結論，再看細節：**只做偶爾問答、寫草稿、查資料，免費版通常夠用；每天靠它幹活、常要深度研究或寫程式，再考慮 Plus；Pro 是給用量大到 Plus 天天撞牆的人，不是給「怕不夠用」的人。**

- **免費版能做什麼：** 基礎對話、檔案上傳、圖片生成、語音對話都有，但用量有限制，額度用完會降級或排隊。免費版目前用 Luna 檔模型，複雜推理與長任務比付費檔的 GPT-6 弱一截。
- **Go 適合誰：** 每月 8 美元，比免費版多一點額度與功能，但仍可能含廣告、仍沒有 Plus 的思考檔位。適合「免費版不太夠、又不想付 20 美元」的中間需求。
- **Plus 適合誰：** 每天使用的個人主力。20 美元換來 GPT-6（Sol 驅動）、更完整的深度研究、圖片與檔案額度、排程任務、自訂 GPTs、Codex 擴充額度。對大多數人來說，Plus 是性價比的頂點。
- **Pro 適合誰：** Plus 天天撞用量上限、或需要 GPT-6 Pro（Astra 驅動）處理最難任務的人。Pro 100 是起點；200 與 500 只是額度更大，不是模型更強。先確認自己真的撞牆再升級，不要為「以防萬一」多付 80 美元。
- **Business 與 Enterprise：** 團隊協作、管理權限與資料保護是重點，個人用戶不需要。Business 標準席每月含 15 條 Pro 訊息、高級席每週 50 條（與 GPT-5.6 Sol Pro 共用額度），以官方幫助文章為準。

想先比較三家再決定，可以看本站的 [ChatGPT vs Claude vs Cursor 深度對比](/posts/chatgpt-vs-claude-vs-cursor-guide/)；已經有 Claude 帳號的人，也可以對照 [Claude 入門完整指南](/posts/claude-guide/)，看哪家更適合自己的任務。

## 功能一覽

ChatGPT 不只是一個聊天框。以下是 2026 年 11 月各方案共有的主要功能，細節與用量依方案而定：

- **對話與思考檔位：** Instant、Medium、High、Extra High 四檔思考深度，任務越難檔位越高；Pro 另有 GPT-6 Pro 檔位。
- **記憶：** 記住偏好與上下文，跨對話沿用；可在設定裡查看、關閉或清除。
- **圖片生成與編輯：** 對話框裡一句話或一張照片生成圖片，可調細節；免費版也有，但額度較少。
- **語音對話：** App 與網頁都能語音交談，適合通勤與口述整理。
- **Canvas：** 長文寫作與程式碼的並排編輯區，邊寫邊改，不用在對話串裡來回翻。
- **深度研究：** 多步驟聯網研究後交一份帶來源的報告，適合寫報告、做競品調查前的資料收集。
- **檔案上傳與數據分析：** 上傳文件、表格、圖片後做摘要、整理、畫圖表。
- **Projects（專案）：** 把對話、檔案、自訂指令收在一個專案裡，適合長期任務。
- **自訂 GPTs：** 不用寫程式就能做一個專用助手；Plus 以上可用。
- **排程任務：** 定時提醒或定時執行任務，Plus 以上可用。
- **ChatGPT Work 與 Codex：** 面向長時間任務與程式開發的工作區與編程代理，Plus 以上可用，模型選項與聊天框不同（見上文）。
- **Dot：** Pro 方案包含的新功能入口，開放資格依帳號而定，細節以官方公告為準。

## 國內用戶怎麼用

這一段只寫已確認的事實，不寫未經證實的說法：

- **OpenAI 不向中國大陸提供服務。** 這是官方服務範圍，國內用戶要用，必須同時解決帳號、支付、網路環境與風控四個問題，缺一不可。
- **四關的具體卡點與路線，見本站總綱：** [ChatGPT、Claude、Gemini 國內怎麼開通：帳號、支付、網路、防封四關總綱](/posts/chatgpt-claude-gemini-china-access-guide/)。其中最難的通常是支付與風控：沒有海外銀行卡就開不了會員，網路環境不穩就容易觸發封號。
- **先想清楚要不要折騰。** 如果只是日常問答、寫作、查資料，Kimi、DeepSeek 等國產模型國內直連、免費可用，往往是更省心的選擇；只有確實需要 ChatGPT 獨有功能（例如 Codex、特定 GPTs）時，才值得走開通流程。
- **代充與帳號買賣有風險。** 付款前先看清賣家條款與售後，帳號異常、訂閱中斷的申訴路徑要先問清楚，不要只看價格。

## 常見問題

**免費版和 Plus 最大的差別是什麼？**

模型與額度。免費版用 Luna 檔模型、用量有限；Plus 用 GPT-6（Sol 驅動）、額度更大，並有深度研究、排程任務、自訂 GPTs 等完整功能。只是偶爾問問題，差別不大；每天幹活，差別很明顯。

**Plus 20 美元可以年付便宜一點嗎？**

不可以。OpenAI 官方說明個人付費方案只有月付，沒有年付或一次付多個月的選項。Business 方案年付才有折扣（每人每月 20 美元，年付價；月付 25 美元）。

**Pro 100、200、500 的模型一樣嗎？**

模型一樣，都是 GPT-6 Pro（Astra 驅動）與 GPT-6（Sol 驅動）。差別在用量額度與 API 額度：500 檔額度最高，另含 Ultrafast。不是越貴模型越強，是越貴額度越多。

**GPT-6.1 Terra 為什麼在聊天框選不到？**

因為它只在 Work 與 Codex 提供，不在普通對話裡。這是官方的產品劃分，不是帳號問題。它的定位是高頻 agent 任務的便宜快速模型，詳見本站 [GPT-6.1 Terra 發布](/posts/2026-10-27-gpt-6-1-terra-launch/)。

**GPT-6 Cyber 是給普通用戶的嗎？**

不是。它是網路安全專用模型，只開放給審核通過的 Daybreak Red 安全團隊，普通帳號用不上。詳見本站 [GPT-6 Cyber 發布](/posts/gpt-6-cyber-launch/)。

**國內能直接註冊 ChatGPT 嗎？**

不能直接註冊使用。OpenAI 不向中國大陸提供服務，需要另外解決帳號、支付、網路與風控問題，具體見本站開通總綱。不要輕信「國內直連、包開通」的說法。
