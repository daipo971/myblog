**结论先说：Token 是大模型处理文字的最小单位，模型不是按字、也不是按词读你的话，而是先把文字切成一串 token 再处理。API 按 token 收费，就是按你发过去和模型生成的 token 数收费；手机 App 免费不等于不用 token，只是平台替你付了这笔钱。** 下面用真实分词数据把「一个 token 多大」「一次对话花多少」算清楚。

![Token 封面插画：一段文字被剪成彩色拼图块，机器人伸手接住其中一块](/images/what-is-token/cover.webp)

## Token 是什么

把一句话交给大模型之前，模型会先用一个叫「分词器」（tokenizer）的工具，把文字切成一小块一小块，这些小块就是 token。切分规则由每个模型自己定，常见方法是 BPE（字节对编码）：出现频率高的词组会被切成一大块，少见的词会被拆得更碎。

可以这样理解：token 就像乐高积木的最小零件。模型读到的不是一整句话，而是一串零件编号；它理解意思、生成回答，都是在这些零件的基础上进行的。零件切得越碎，同一句话的 token 数就越多，处理成本也越高。

一个 token 可以是一个词、半个词、一个标点，甚至一个汉字的一部分。具体切成什么样，取决于分词器，不取决于你。

## 一句话会被切成几个 Token

同一句话在不同分词器下 token 数不一样。用开源分词工具 tiktoken，对几句话实际切分，结果如下（切分时间 2026 年 11 月 14 日，工具版本以当时为准）：

| 句子 | 字符数 | 旧版分词器 cl100k_base | 新版分词器 o200k_base |
| --- | --- | --- | --- |
| Hello, how are you today? | 25 | 7 | 7 |
| The quick brown fox jumps over the lazy dog. | 44 | 10 | 10 |
| 你好，今天过得怎么样？ | 11 | 12 | 7 |
| 人工智能正在改变我们的工作方式。 | 16 | 14 | 8 |
| 请帮我把这份会议纪要整理成三点：第一，项目进度；第二，遇到的问题；第三，下一步计划。 | 42 | 45 | 32 |

能看出三个规律：

- **英文很省**：44 个字符的英文句子只要 10 个 token，平均一个 token 约 4 个字符。OpenAI 官方给的估算也是这个口径：英文 1 个 token 约 4 个字符、约四分之三个单词，100 个 token 约 75 个单词。
- **中文曾经很贵，现在便宜多了**：旧版分词器下中文大约 1 个字就要 1 个 token；新版分词器把常见汉字组合并，11 个字的短句只要 7 个 token。中文用户为 token 多付费的情况，比两年前已经明显改善。
- **标点和格式也占 token**：换行、空格、引号都会被切分。复制粘贴带大段格式的文本，或者让模型输出带复杂排版的内容，token 都会悄悄变多。

所以「token 数」和「字数」不是一回事，跨语言、跨模型都不能直接换算。想知道准确数字，最可靠的办法是用对应模型的官方分词工具当场数，而不是凭感觉估。

## 为什么 AI 按 Token 收费

按 token 收费是 API 的计价方式，一次调用通常分四种 token 计费：

- **输入 token**：你发给模型的所有文字，包括提示词、上传的文档和对话历史。每轮对话都会把前面的历史重新发一遍，所以聊得越久，每轮的输入 token 越多。
- **输出 token**：模型生成的文字。回答越长越贵，推理模型在内部思考用的 token 也算输出，哪怕你看不到思考过程。
- **缓存命中输入 token**：重复发送过的内容（比如固定的人设提示词、同一份长文档反复问），部分平台会按更低的缓存价计费，有的只要正常输入价的几十分之一。
- **推理 token**：推理模型在给出答案前内部推演消耗的 token，同样按输出价计费。答案看着短，账单未必短。

价格单位一般是「每百万 token 多少美元或人民币」。本站的[中国大模型 API 价格表](/posts/china-llm-api-pricing/)整理了 8 家厂商旗舰模型的输入输出价（查阅时间 2026 年 11 月 7 日），最便宜的输入价是每百万 token 0.15 美元，最贵的是 2 美元，相差 13 倍。

手机 App 里聊天免费，是因为平台把 token 成本包进了会员费或广告收入；一旦你用 API 把模型接进自己的应用，就要自己按 token 买单。免费和付费的区别不在 token 本身，而在谁付账。

## 算一笔账：一次对话到底花多少钱

用本站价格表里查到的价格（2026 年 11 月 7 日查阅，付款前以官方价目表为准），拿最便宜的一档算一算：

- **日常问答**：发一句 50 字的问题（约 40 个 token），模型回 500 字（约 700 个 token）。用输入 0.15 美元、输出 0.60 美元的模型，一次对话成本约 0.0004 美元，几乎可以忽略。
- **读一份 10 万字文档再提问**：文档约 7 万 token，输入成本约 0.01 美元；模型写 2000 字回答约 3000 个输出 token，约 0.0018 美元；合计约 0.012 美元。
- **换成最贵的旗舰模型**：同样的任务，输入 2 美元、输出 10 美元，成本约 0.17 美元，是便宜模型的 14 倍。

普通人日常用 App 不用算这笔账；但当你要做批量处理（比如每天处理上千份文档）、或者在自己的产品里调用 API，模型选型直接决定成本量级。先在 App 里试效果，确定要接入再开 API，是最稳妥的顺序。

## 上下文窗口就是 Token 上限

每个模型都有「上下文窗口」，也就是一次请求里输入加输出最多能容纳的 token 数，常见的有 128K、256K、1M（100 万）。按新版分词器估算，100 万 token 大约能装 140 万字中文——注意这是估算值，不同文本、不同分词器会有浮动。

窗口满了会怎样，取决于产品设计：有的直接报错让你缩短输入，有的悄悄丢掉最早的对话内容，有的自动做摘要压缩。长对话越聊越「失忆」，多半是窗口不够用了，而不是模型变笨了。

判断一个模型够不够用，不用记具体数字，记住这个对照就行：128K 窗口约能装十几万字，够读一本薄书；1M 窗口约能装上百万字，够读一整套资料。日常聊天远远用不满，真正吃窗口的是带着长文档反复追问的场景。

## 省 Token 的 5 个办法

1. **提示词写短一点**：同样的要求，一句话能说清就别写三段。啰嗦的提示词每轮对话都要重复计费。
2. **别反复贴同一份长文档**：先确认平台有没有开上下文缓存；没有缓存时，把文档摘要成要点再发，比全文反复贴便宜得多。
3. **控制输出长度**：明确告诉模型「回答控制在 300 字内」「只列要点」，输出 token 直接减少。
4. **轻任务用轻量模型**：查资料、改写、摘要这类任务，便宜模型的输入价只有旗舰的十分之一左右，效果往往够用。
5. **长对话及时开新会话**：历史越攒越长，每轮输入 token 越来越多。换个话题就开新对话，别在一个窗口里聊所有事。

## 常见误解

- **「Token 就是字数」**：不是。英文 1 个 token 约 4 个字符，中文 1 个字在新版分词器下约 0.6–0.7 个 token，旧版约 1 个。字数和 token 数没有固定换算关系。
- **「Token 就是单词」**：也不是。一个单词可能被拆成多个 token（比如不常见的专有名词），多个常见词也可能合并成一个 token。
- **「免费 App 不用 token」**：用的，只是平台替你付了。免费额度的本质是平台每月替你承担一定量的 token。
- **「中文一定比英文贵」**：曾经是，现在分词器改进后差距已经很小。真正决定成本的是模型定价，不是语言。
- **「输出越长越好」**：输出按 token 收费，废话是要付钱的。让模型先给结论、再展开细节，既省钱也省时间。

## 常见问题

**怎么查一段话是多少 token？**

最准确的是用对应模型的官方分词工具，比如 OpenAI 的在线 Tokenizer（platform.openai.com/tokenizer），粘贴文字就能看到切分结果和数量。也可以用开源工具 tiktoken 在本地批量计算。注意不同模型的分词器不一样，跨模型比较时要用各自的工具分别数。

**聊天 App 里的 token 和 API 的 token 是一回事吗？**

是一回事。区别只在计费对象：App 的 token 成本由平台承担（包在会员费或免费额度里），API 的 token 由调用者按量付费。同一句话，在同一个模型下切出来的 token 数是一样的。

**为什么同一句话，不同模型 token 数不同？**

因为每个模型用的分词器词表不同。词表越大、越针对某种语言优化，同样的文字切出来的 token 就越少。这也是比较模型价格时不能只看单价的原因：单价低的模型如果分词效率差，总成本未必低。

**上下文窗口写着 1M，是不是一次能发 100 万字？**

不是。1M 指的是 100 万 token，不是 100 万字；按新版分词器估算，100 万 token 大约对应 140 万字中文。而且窗口是输入加输出共享的，留给输出的空间也要预留出来。

**推理模型为什么账单比看起来贵？**

推理模型在给出答案前会先内部推演，这些推理 token 不显示在回答里，但按输出价计费。答案只有几行字，背后可能消耗了几千个推理 token。看账单时要看总 token 数，不只看回答长度。
