**做完你会得到：** 一个任意国家/地区的 Apple ID，知道怎么绑卡、不用卡怎么付费、怎么换区、怎么和国区号一起用。大约需要 20–30 分钟，费用 0 元起（不绑卡只下免费应用）；要付费则按需充值。

## 先说清三个真相（开始前必读）

很多人卡住不是因为步骤难，是因为对规则有误解。先把三句话讲透，后面就顺了。

**第一，账号国家可以任意选，但付款方式必须和账号国家匹配。** Apple 校验的是账单地址国家：美区号要美国发行的卡或美国账单地址，中国发行的 Visa、Mastercard 即使是双币卡，账单国家是中国，绑美区号会被拒。这不是卡坏了，是地区规则。

**第二，不绑卡也能注册、能用。** 付款方式选「无」，免费应用随便下；要买付费应用或订阅，用对应国家的礼品卡充值。注意卡区和号区必须一致：美区卡只能充美区号，日区卡只能充日区号，买错区充不进去。

**第三，手机号不用当地号。** 注册验证可以用 +86 手机号收短信验证码；只有 Apple Pay、部分需要当地身份的服务才可能要求当地信息。生日建议填真实的，未成年账号会受家长控制限制，功能不全。

## 准备工作

- [ ] 一个没注册过 Apple ID 的邮箱（新邮箱最稳；已注册过的邮箱不能重复注册）
- [ ] 能收短信的手机号（+86 就可以）
- [ ] 想好国家/地区：美区应用最全、日区有部分独占、港区中文友好且部分服务更近。按你要用的 App 选，不要跟风选冷门区（冷门区礼品卡难买）
- [ ] 网络：注册时 IP 与所选国家不一致可能多一道验证，用对应国家的网络环境更顺（不是强制，但能少折腾）
- [ ] （可选）对应国家的礼品卡：如果打算付费，提前备好

## 第 1 步：网页注册（5 分钟）

1. 打开 https://appleid.apple.com/ ，点「创建 Apple ID」（页面语言可切换，不影响账号国家）。
2. 填姓名（拼音即可）、生日（真实的）、邮箱（将作为账号名）、密码（至少 8 位，含大小写字母和数字）。
3. 「国家/地区」下拉框选目标国家。这一步决定了你的商店地区，后面能改，但改区有前提，见第 5 步。
4. 手机号：区号选 +86，填国内手机号，选短信验证，收 6 位验证码填入。
5. 邮箱收验证码填入，点继续，账号就建好了。

注意：不要用已注册过的邮箱；一个手机号可以验证多个 Apple ID，但同一天批量注册多个号会触发「无法创建」（见报错表）。

## 第 2 步：App Store 登录并激活（关键：付款方式选「无」）

1. iPhone 上不要直接在「设置」顶部退出 iCloud 换号（会动通讯录、照片同步）。正确做法是只换商店账号：打开 App Store → 右上角头像 → 拉到最底点「退出登录」→ 再登录刚注册的外区号。iCloud 保持国区号不动。
2. 首次进入外区商店，会弹「检查账户信息」：点「检查」→ 同意条款 → 到付款方式页。
3. 付款方式选「无」（None）。如果没有「无」这个选项，先排查：账号有未付余额、有未取消的订阅、加入了家人共享、刚改过地区——处理完再回来选。
4. 账单地址：按该国格式填（美国：姓名、街道、城市、州、5 位邮编；日本：7 位邮编、都道府县）。地址栏只用于商店地区校验，不需要是真实住址，但不要编造他人真实地址或用于支付欺诈；只是免费账号的地址信息。
5. 电话栏填手机号（+86 也可，按提示格式来）。完成后商店就切换到外区了，可以下载免费 App。

## 第 3 步：绑卡（要付费时再做）

能绑的卡：该国发行的 Visa、Mastercard、American Express（借记卡或信用卡都行，前提是发卡行支持境外 Apple 扣款）。

路径：设置 → 顶部 Apple ID → 「付款与配送」→ 「添加付款方式」→ 选卡 → 填卡号、有效期、安全码、账单地址（必须和账号国家一致）。

为什么中国卡绑不上：Apple 按账单地址国家校验付款方式，中国账单地址的卡对不上外区号，提交时会被拒或提示「付款方式不适用于此地区」。这不是换张中国卡就能解决的，根源在账单国家。

绑卡失败先查：卡是否开通境外在线支付、账单地址国家是否和账号国家一致、卡片是否过期、发卡行是否拦截（可致电银行确认）。

## 第 4 步：不绑卡的付费办法（礼品卡）

1. 买对应国家的礼品卡：美区号买美国区卡，日区号买日本区卡，卡区和号区必须一致，否则兑换时报错。
2. 兑换：App Store → 右上角头像 → 「兑换充值卡或代码」→ 手动输入卡密或相机扫描 → 金额进账号余额。
3. 余额可用于买付费应用、内购、订阅；有余额时优先扣余额。
4. 避坑：明显低于面值的卡别碰（盗刷卡买的「黑卡」），苹果追查会作废余额甚至封号；只走经营多年的正规渠道，电子卡密优先于实体卡（实体卡注意覆膜完整）。

## 第 5 步：换区（改国家/地区）

前提（缺一不可）：账号余额花到 0、取消所有订阅、退出家人共享。

路径：设置 → Apple ID → 「媒体与购买项目」→ 「查看帐户」→ 「国家/地区」→ 选新区 → 同意条款 → 选付款方式（可再选「无」）→ 填新区地址。

提醒：换区后原区购买的 App 仍在原区账号名下，更新时要切回原区；部分内容新区可能没有；不要频繁换区，会触发风控。

## 第 6 步：双账号日常用法（推荐）

国区号留在 iCloud（照片、通讯录、查找、Apple Pay 都正常），外区号只登 App Store 下应用。需要更新外区 App 时，切到外区商店更新完再切回；两个号的购买记录互不干扰。这是目前最稳的用法，不用来回退出 iCloud。

## 常见报错与解决

| 报错/现象 | 原因 | 解决 |
| --- | --- | --- |
| 付款方式被拒 / 「此付款方式不适用于此地区」 | 卡的账单国家与账号国家不一致 | 换该国发行的卡，或改用礼品卡；不要反复提交，频繁失败会锁卡验证 |
| 付款方式里没有「无」 | 有未付余额、未取消订阅、家人共享成员、刚改区 | 清掉余额、取消订阅、退出家人共享后再回来选 |
| 收不到短信验证码 | 运营商拦截、号码近期验证过多 | 等一会儿重发；换个手机号；检查短信拦截设置 |
| 「无法创建 Apple ID」/ 注册被拒 | 同一设备/IP 短时间内注册过多 | 换网络环境，隔天再试；不要批量注册 |
| 礼品卡无法兑换 | 卡区与号区不一致 | 确认卡的国家与账号国家一致，买错区只能转卖或换号 |
| 账单地址无效 | 邮编/州/格式与所选国家不符 | 按该国格式重填：美国 5 位邮编、日本 7 位邮编 |
| 订阅扣费失败 | 余额不足或卡被拒 | 先充值余额或换有效付款方式，再恢复订阅 |

## 常见问题

**问：中国发行的 Visa 双币卡到底能不能绑美区号？**

答：一般不能。Apple 校验的是账单地址国家，不是卡组织。中国账单地址的卡对不上美区号，提交会被拒。想付费就用美区礼品卡，或者办该国发行的卡。

**问：+86 手机号能注册美区、日区号吗？**

答：能。注册验证只要求手机号能收短信，+86 没问题。只有 Apple Pay、部分需要当地身份的服务才可能要求当地信息。

**问：一个手机号能验证几个 Apple ID？**

答：可以验证多个，但别同一天批量注册，会触发风控导致「无法创建」。正常自用几个号没问题。

**问：换区后以前买的 App 还在吗？**

答：在原区账号名下，不会消失，但更新要切回原区才能更新；新区看不到原区专属内容。

**问：未成年能注册外区号吗？**

答：能注册，但会受家长控制限制（购买需批准、部分内容不可见），建议成年人用自己的生日注册。

**问：外区号能用 Apple Pay 吗？**

答：Apple Pay 绑卡同样要求卡的发行国家与账号地区匹配，中国卡绑外区号的 Apple Pay 同样行不通；日常支付还是用国区号。
