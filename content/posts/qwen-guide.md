**通义千问 Qwen 是阿里巴巴的大模型家族，当前主力是 2026 年 8 月发布的 Qwen3.8 一代，旗舰 Qwen3.8-Max 走 API 与开放权重两条线，小尺寸的 Qwen3.8-27B 用 Apache 2.0 协议，普通人直接用免费的 Qwen App 就够，开发者按价格和许可证选版本。** 这一页是 Qwen 的档案页：版本、规格、价格、许可证和用法集中放在这里，每次有新版本都会更新。

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 公司 | 阿里巴巴，通义千问（Qwen）团队 |
| 当前主力 | Qwen3.8 一代（2026 年 8 月起陆续发布） |
| 旗舰 | Qwen3.8-Max：2.4 万亿参数 MoE，每次推理激活约 950 亿参数，托管 API 上下文 100 万 token |
| 消费端入口 | Qwen App（原通义 App，2025 年 11 月更名）、网页版 |
| API 入口 | 阿里云 Model Studio（国内对应百炼平台），模型名 `qwen3.8-max` 等 |
| 开源情况 | 各版本许可证不同，见下文「许可证怎么选」 |

Qwen 和 ChatGPT、Claude 最大的区别是开放程度：同一代里既有旗舰级开放权重，也有能在单张高端显卡上跑的中尺寸模型。代价是版本多、名字像，选错版本很容易多花钱或踩许可证的坑。

## 版本时间线

| 时间 | 版本 | 要点 |
| --- | --- | --- |
| 2023 年 | 通义千问首次亮相 | 阿里巴巴大模型业务的起点，后续演进为 Qwen 系列 |
| 2025 年 9 月 | Qwen3-Max | 万亿参数级别的旗舰，据发布时报道训练数据约 36 万亿 token，API 优先 |
| 2025 年 11 月 | Qwen App | 原通义 App 更名并升级为消费端主力，定位对标 ChatGPT 的免费助手 |
| 2026 年 8 月 3 日 | Qwen3.8-Max（托管 API） | Qwen3.8 一代旗舰上线，100 万 token 上下文，支持图文与视频输入 |
| 2026 年 8 月 12 日 | Qwen3.8-2.4T-A95B（开放权重） | 旗舰的底座权重放出，纯文本、始终思考模式，自定义 Qwen3.8-Max License |
| 2026 年 8 月 14 日 | Qwen3.8-27B（开放权重） | 270 亿参数稠密多模态模型，Apache 2.0，据第三方报道首周下载超 680 万次 |
| 2026 年 8 月下旬 | Qwen3.8-Flash 与 Flash-Next | 速度优先的 Flash 上线；Flash-Next 被描述为下一代 Qwen4 架构的早期预览 |
| 2026 年 9 月 | Qwen3.8-Max 0902 与 Max Prime | 9 月刷新版与高吞吐 SKU，Max Prime 面向高并发场景 |
| 2026 年 9 月 20 日 | Qwen-Image-2.1 | 图像生成基座开源，7B 视觉生成架构，原生支持透明图与多图参考 |
| 2026 年 10 月 9 日 | Qwen-Image-2.1-Turbo | 图像加速版开源，8 步去噪完成生图与编辑，Qwen Research License |
| 在研 | Qwen4 | 阿里在 2026 年云栖大会上表示正在训练中，未公布发布时间与规模 |

注意区分「Qwen3-Max」和「Qwen3.8-Max」：前者是 2025 年的上一代旗舰，后者是 2026 年 8 月的现任旗舰；另有「Qwen3.8-27B」这个同名中尺寸模型，能力与旗舰不在一个档位，对比跑分时先确认测的是哪一个。

## Qwen3.8 家族对照

| 版本 | 定位 | 开放权重 | 许可证 | 适合谁 |
| --- | --- | --- | --- | --- |
| Qwen3.8-Max（托管 API） | 旗舰，长程编程与专业任务 | 否，API 调用 | API 服务条款 | 开发者、企业长文档与 Agent 任务 |
| Qwen3.8-2.4T-A95B | 旗舰底座权重 | 是，BF16 与 FP8 | 自定义 Qwen3.8-Max License | 有多卡服务器的团队 |
| Qwen3.8-27B | 中尺寸多模态 | 是 | Apache 2.0 | 个人开发者、本地部署、二次开发 |
| Qwen3.8-Flash | 速度与成本优先 | 托管为主 | API 服务条款 | 高频、轻量调用 |
| Qwen3.8-Flash-Next | 下一代架构预览 | 是 | Qwen Community License 1.0 | 想提前试新架构的开发者 |
| Qwen-Image-2.1 / Turbo | 图像生成与编辑 | 是（Turbo 为加速版） | Qwen Research License | 电商、设计场景的出图需求 |

跑分方面只说可核实的部分：Qwen 官方称 9 月刷新后的 Max 在 GPQA Diamond 上达到 92.8%，这是官方自报数据，未经独立复现；第三方评测机构 Artificial Analysis 给开放权重版的智能指数为 58 分。日常选型不用追跑分榜，看下面价格和许可证两条就够了。

## 价格与许可证

**API 价格（国际站 Model Studio 口径，每百万 token，价格以官网实时价目为准）**

| 版本 | 输入 | 输出 |
| --- | --- | --- |
| qwen3.8-max | $2 | $6 |
| Qwen3.8-Max Prime | 未逐项核实 | 第三方对比称输出约 $12，属高吞吐 SKU，定价高于标准 Max |

国内百炼平台的人民币价目与国际站不完全一致，本文不逐项列人民币价，下单前以百炼官网为准。图像方面，据公开报道，百炼上 Qwen-Image-2.1-Turbo 为 0.1 元/张，同样以官网为准。

**许可证怎么选（商用前必读原文）**

- **Qwen3.8-27B 是 Apache 2.0**，限制最少，个人与商业二次开发都方便，是家族里最省心的开放版本。
- **Qwen3.8-2.4T-A95B 用自定义 Qwen3.8-Max License**，不是 Apache 2.0：对外提供模型服务或 AI 助手业务且收入超过一定门槛（公开梳理称连续 12 个月超 5000 万美元）需要另行取得许可；超大规模产品还涉及模型名称展示要求。普通内部使用不受影响，但对外服务前务必读许可证原文。
- **Qwen-Image-2.1 与 Turbo 用 Qwen Research License**，按公开梳理仅限非商业研究与评估，商用需另行许可，不能默认当成可商用素材模型。
- **Flash-Next 用 Qwen Community License 1.0**，对模型服务类商业使用同样有额外许可要求。

一句话：想省事商用，优先选 27B；想用旗舰权重对外服务，先找法务看许可证原文。

## 国内怎么用与本地部署

**普通人：用 Qwen App**

1. 手机应用商店搜「Qwen」，或打开网页版，手机号注册即可使用。
2. 日常聊天、查资料、写文档、做 PPT、语音与拍照输入都在 App 内完成，基础功能免费、有用量上限。
3. 公开资料对 Qwen App 是否有付费档说法不一，本文不写死：以你手机上 App 内的实际页面为准，不要轻信第三方「会员开通教程」。
4. Qwen App 与 API 是两套体系：App 里的用量不等于 API 额度，开发者要单独在百炼开 API。

**开发者：调 API**

1. 在阿里云 Model Studio（国内为百炼平台）开通服务、创建 API Key。
2. 按模型名调用：旗舰用 `qwen3.8-max`，便宜快速用 Flash，图像用 `qwen-image-2.1-turbo`。
3. 长上下文任务（整本代码库、几百页合同）是 Max 的主场，100 万 token 上下文不用自己切文档；但思考模式会多耗 token，简单问答换 Flash 更划算。

**本地部署：先看显存再动手**

- Qwen3.8-27B 是个人能跑的版本，据公开资料属于单张高端显卡可推理的规格，Ollama、vLLM 等主流框架都支持，具体显存需求以模型卡为准。
- Qwen3.8-2.4T-A95B 是数据中心级别的模型，需要多卡服务器，个人电脑不用考虑；而且开放权重是纯文本版，托管 API 才有的视觉输入、非思考模式和内置工具，下载权重是得不到的。
- 本地部署的通用流程（Ollama、LM Studio、显存估算）见 [本地部署大模型教程](/posts/ai-local-llm-guide-2026/)。

## 常见问题

**Qwen App 免费吗？**
基础功能免费，有用量上限。是否有付费档、额度怎么算，公开资料说法不一，以 App 内实际页面为准。

**Qwen3.8-Max 和 Qwen3.8-27B 是同一个模型吗？**
不是。Max 是 2.4 万亿参数的旗舰，27B 是 270 亿参数的中尺寸模型，两者名字都带 Qwen3.8，但能力、价格、许可证全都不同。

**下载权重就能得到和 API 一样的 Max 吗？**
不能。开放权重是纯文本底座且始终思考模式；托管 API 额外提供视觉输入、非思考模式和内置工具。

**Qwen3.8-27B 商用有限制吗？**
它是 Apache 2.0，限制最少。但商用前仍建议确认你用的检查点附带的许可证文件，因为同系列其他版本用的是不同许可证。

**Qwen4 什么时候出？**
官方只说正在训练中，未公布时间、规模与许可证，市面上的 Qwen4 发布时间表均为猜测。
