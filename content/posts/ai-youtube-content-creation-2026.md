## 第一步：选题和脚本 — Claude / ChatGPT

**工具：** Claude（主力）+ ChatGPT（补充）

做视频最难的是选题。我的方法是：

### 选题思路

让Claude帮我做**关键词挖掘**：

```
你在YouTube上做一个[AI教程/科技评测/效率工具]频道。
请列出2026年7月这个领域最热门、搜索量最大的10个选题，
每个选题附上搜索量和竞争度分析（高/中/低）。
```

Claude会分析当前趋势，给出选题建议。我通常会从里面挑2-3个感兴趣的，然后做进一步细化。

### 写脚本

选定选题后，让Claude写完整的视频脚本：

```
帮我写一个8分钟的YouTube视频脚本，题目是"XXX"。

目标观众：25-40岁，对技术感兴趣但不是专业程序员。
风格：口语化，像朋友聊天一样。
结构：
1. Hook（前15秒抓住注意力）
2. 问题引入（30秒）
3. 方案介绍（2分钟）
4. 实际操作演示（3分钟）
5. 对比分析（1分钟）
6. 总结和建议（30秒）
- 每一段标注大概的时间长度
- 在关键地方标注画面建议
```

我常用的技巧：生成第一版之后，再让Claude做**口语化改写**——把书面语改成口语，加一些语气词和停顿。

## 第二步：配音 — Fish Audio / ElevenLabs

**工具：** Fish Audio（中文）/ ElevenLabs（英文）

脚本写好了，下一步是配音。我之前试过自己录，但每次都要录好几遍，太浪费时间了。

现在我用 **Fish Audio** 克隆了自己的声音，然后直接把脚本贴进去生成配音。

具体操作：
1. 在Fish Audio录3-5分钟的样本声音
2. AI完成克隆（大约10分钟）
3. 贴入脚本生成配音
4. 导出为WAV或MP3文件

生成之后我会快速听一遍，主要注意：
- 专业术语的发音是否准确
- 语速是否自然（必要时调整）
- 段落之间是否有合适的停顿

如果某句话的语调不对，只需要重新生成那一句，不用整段重来。

👉 [Fish Audio](https://fish.audio/)
👉 [ElevenLabs](https://elevenlabs.io/)

## 第三步：素材获取 — Pexels / AI生成

视频需要有画面配合。我的素材来源：

### 免费素材库
- **Pexels** - 高质量免费视频素材
- **Pixabay** - 同样免费，种类更全
- **Coverr** - 专门为视频创作者设计的免费素材

### AI生成素材
- 如果有需要讲解的概念图 → **Midjourney / DALL-E** 生成
- 需要动态演示 → **Runway / 即梦** 图生视频
- 数据可视化 → **Flourish** 生成动态图表

### 录屏素材
做教程类视频需要录屏：
- **OBS** - 免费，功能最强
- **Screen Studio** - 美观但付费（$90一次性）

## 第四步：剪辑 — CapCut（剪映国际版）

**工具：** CapCut（免费）

剪辑我用剪映国际版 CapCut。免费版功能完全够用。

**我的剪辑流程：**

1. **导入配音** — 作为主音轨
2. **自动字幕** — CapCut的AI语音识别生成字幕，一键校对
3. **对齐素材** — 导入视频素材，对齐到配音
4. **加过渡效果** — 简单的淡入淡出
5. **加文字标注** — 关键概念用文字强调
6. **背景音乐** — 用CapCut自带的免费音乐库
7. **导出** — 1080p 30fps

几个实用技巧：
- **按段落剪辑**：根据脚本的段落剪辑，这样出错时不用全改
- **善用快捷键**：剪映的快捷键可以大幅提升速度
- **B-Roll素材要克制**：一个画面不要超过5秒，但也不要频繁切换

整个剪辑过程大约30-40分钟。

## 第五步：封面 — Canva AI

**工具：** Canva（免费版）

封面决定了用户会不会点进来看。我用 Canva 的AI功能做封面：

1. 用Canva Magic Media生成主题背景图
2. 套用YouTube封面模板（16:9）
3. 加上标题文字（大字、高对比度）
4. 调整颜色搭配

**封面设计的几个原则：**
- **标题小于5个字** — 封面空间有限，字多了看不清
- **高对比度** — 在列表页中一眼能看到
- **人物大脸特写** — 心理学研究表明人脸更容易吸引注意力
- **品牌统一** — 保持一致的字体和色调

## 新手建议

如果你刚开始做YouTube，别追求完美：

1. **先发再优化** — 第一版视频不用太完美，发了再说
2. **3条视频试方向** — 前3条视频用来确定你的风格和定位
3. **关注完播率** — 前15秒最重要，把最吸引人的内容放前面
4. **固定更新频率** — 每周固定时间发布，培养观众习惯

AI工具让视频创作的门槛大幅降低了。两年前做一条10分钟的教程视频可能要一周，现在AI帮你完成了80%的工作。

最大的门槛不再是技术，而是**你有没有内容想表达**。
