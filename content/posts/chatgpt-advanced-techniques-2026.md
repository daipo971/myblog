**结论先说：** 想把 ChatGPT 从「聊天工具」变成真正的工作助手，最值得掌握的是四件事：用 **Projects** 把资料和指令固定下来，用**自定义 GPT** 把重复任务做成专用助手，用**结构化输出**让结果稳定可用，用**记忆**让它了解你。下面的 10 个技巧按这个思路展开，每个都附可以直接套用的写法。

**说明：** 本文依据 OpenAI 官方帮助文档整理（2026 年 10 月查阅）。ChatGPT 的功能名称、位置和各套餐可用范围经常调整，以官方说明为准。

## 技巧一：Projects（项目管理）

Projects 是 ChatGPT 里最实用的功能之一。

**它能做什么：**
每个Project是一个独立的上下文环境，包含：
- 专属的对话历史
- 可上传的参考文件（PDF/WORD/图片）
- **自定义指令**（针对这个Project的专属提示词）
- 项目内所有对话共享上下文

**实操案例：**

以「博客写作」Project 为例：
1. 上传写作规范、关键词表、已发布文章清单
2. 设置项目指令：「按写作规范写作，关键词自然融入，每篇推荐 2 篇相关旧文」
3. 项目里的所有对话都会参考这些资料，不用每次重新交代背景

**设置方法：**
```
ChatGPT → 左侧栏 → Projects → 新建Project → 上传文件 + 设置指令
```

## 技巧二：Custom GPTs（定制化AI助手）

Custom GPTs 相当于把一套固定的指令和资料打包成专用助手。

**常见的 GPT 示例：**

| GPT名称 | 用途 | 核心指令 |
|---------|------|---------|
| 博客写作助手 | 写博客文章 | 参考知识库，SEO优化，内链策略 |
| 代码审查 | 审查代码质量 | 安全、性能、可维护性全面检查 |
| 翻译助手 | 中英互译 | 保持原文风格，专业术语准确 |
| 数据分析 | 分析CSV数据 | 自动生成可视化报表 |

**不用写代码：** Custom GPTs 的配置界面完全是自然语言，你只需描述它的职责和行为准则。

### 创建流程

1. ChatGPT → Explore GPTs → Create
2. 用自然语言描述你的需求
3. 上传知识文件
4. 设置交互方式
5. 发布（可以只自己用）

**高级技巧：**
- 在Knowledge里上传你的工作文档
- 设置 Actions，让 GPT 调用外部 API（创建 GPT 需要付费套餐，以官方说明为准）
- 给GPTs设定严格的输出格式模板

## 技巧三：自然语言变成程序（无需会编程）

你说需求，ChatGPT生成自动执行的代码。

**实操案例：**

比如批量处理图片：
> "帮我写一个Python脚本，遍历当前文件夹下所有.jpg文件，把它们压缩到200KB以下，宽度统一1024px，保持比例。保存到compressed/目录。"

ChatGPT 会给出完整代码和运行说明。第一次运行前先拿几张图片的副本测试，确认效果再处理全部文件。

**更多可以交给它的自动化任务：**

| 需求 | ChatGPT 会怎么做 |
|-----|---------------|
| 批量重命名文件 | 生成 Python 或命令行脚本 |
| 把 Excel 数据转成 JSON | 生成转换脚本，或直接在对话里用数据分析功能完成 |
| 整理网页表格数据 | 生成脚本（注意遵守网站条款） |
| 图片批量压缩 | 生成 Pillow 脚本 |

**技巧：** 告诉GPT"生成一个完整的脚本，可以直接运行"，它会给完整的代码和说明。

## 技巧四：联网搜索的正确用法

不只是问"今天的新闻"那么简单。

**高级用法：**

1. **实时数据对比**
   ```
   搜索几家 VPS 服务商当前的入门套餐价格，做成表格并附官网来源链接
   ```

2. **竞争对手分析**
   ```
   搜索[你的行业]的头部网站，分析它们的SEO策略和内容结构
   ```

3. **趋势追踪**
   ```
   搜索最近一个月 AI 工具行业的重要新闻，按时间排列，每条附来源
   ```

**注意：** ChatGPT 会在需要最新信息时自动搜索，也可以手动开启搜索。搜索结果仍可能误读来源，重要数字点开链接核对。AI 搜索的常见错误见 [AI 搜索引擎对比](/posts/ai-search-engines-comparison-2026/)。

## 技巧五：长上下文窗口的使用策略

ChatGPT 能处理很长的上下文（具体长度随套餐和模型不同），但不是塞得越多越好：内容越长，模型越容易忽略中间部分的细节。

**有效策略：**

**策略一：渐进式对话**
```
Round 1: "分析这篇文章的大纲"
Round 2: "基于大纲，写第一章"（保留前面的大纲）
Round 3: "继续写第二章，和前文风格保持一致"
```
每次保留关键上下文，不要一次给太多文本。

**策略二：总结-扩展法**
```
Step 1: 让GPT总结长文档的核心要点
Step 2: 基于总结展开详细内容
Step 3: 分模块深入
```

**策略三：分而治之**
```
处理100页PDF：
1. 提取目录和摘要
2. 按章节分批分析
3. 汇总所有分析结果
```

## 技巧六：结构化输出

ChatGPT的输出格式不稳定？你可以强制它输出结构化数据。

**模板技巧：**

```
请严格按以下格式输出：

**问题分析：**
[一段话]

**解决方案：**
1. [步骤一]
2. [步骤二]
3. [步骤三]

**注意事项：**
- [注意点一]
- [注意点二]

**推荐工具：**
| 工具 | 用途 | 价格 |
|-----|------|------|
| [名字] | [作用] | [价格] |
```

**进阶：JSON输出**
```
请以JSON格式输出所有结果，包含：title, description, tags, content四个字段
```

## 技巧七：Memory功能

ChatGPT会记住你在对话中提到的重要信息。

**能记住什么：**
- 你的职业、偏好
- 你常用的工具和技术栈
- 你的项目进展

**管理记忆：**
```
设置 → 个性化 → 管理记忆
```

可以查看和删除ChatGPT记住的任何信息。

**建议：** 定期清理Memory中的过时信息，避免AI参考旧数据。

## 技巧八：图像理解能力

ChatGPT的视觉能力被严重低估了。

**实际应用：**

1. **截图分析**
   ```
   截一张网页，问：这个页面的转化漏斗哪里有问题？
   ```

2. **图表解读**
   ```
   上传Excel图表截图，问：这个数据趋势说明了什么？
   ```

3. **UI设计反馈**
   ```
   上传设计稿截图，问：这个页面在用户体验上有什么改进空间？
   ```

4. **手写笔记数字化**
   ```
   拍一张手写笔记，问：帮我把这些内容整理成电子文档
   ```

## 技巧九：ChatGPT作为编程助手

不只是"写代码"，而是"你的结对编程伙伴"。

**真实工作流：**

**调试：**
```
代码 → 错误信息 → "帮我找出bug原因和修复方案"
```

**代码审查：**
```
"审查这段代码的性能和安全问题，给出改进建议和优先级"
```

**架构设计：**
```
"我要做一个博客系统，帮我设计数据库表结构和API接口"
```

专业开发场景更推荐 Cursor 或 Codex 这类编程工具，见 [AI 编程工具横评](/posts/ai-coding-tools-comparison-2026/)；用 AI 做自动化见 [AI 自动化工具推荐](/posts/ai-automation-tools-2026/)。

## 技巧十：Projects + GPTs + Memory 组合技

把以上技巧组合起来，效果翻倍。

**一个组合用法：**

1. **Memory** 记录你的写作风格、常用工具
2. **Projects**管理不同项目（博客/代码/数据分析）
3. 每个Project里创建**Custom GPTs**处理特定任务
4. 遇到新需求先用**自然语言编程**搞定
5. 复杂分析用**结构化输出**整理结果

关键是让固定的东西（风格、规范、资料）沉淀在 Memory 和 Projects 里，每次对话只需要说清这次的新需求。

## 用好这些技巧的三个原则

**一是先说清背景再提要求。** 告诉 ChatGPT 你是谁、要给谁看、要达到什么效果，比反复修改一句模糊的指令更有效。Projects 和记忆的价值，就在于把这些背景固定下来。

**二是让结果可检查。** 要求它标注来源、列出假设、按固定格式输出，你才能快速判断结果是否可用。对数字、日期和引用，始终回到原始来源核对。

**三是敏感信息不外传。** 公司内部资料、客户数据、个人证件信息不要上传；需要时先脱敏，或在设置里关闭「用于改进模型」的选项。

## 总结

ChatGPT从入门到高级的10个技巧，但核心只有一句话：**不要把它当聊天工具，把它当你的全能搭档。**

高级技巧不是为了炫技，而是为了让你：
- 少做重复性工作
- 减少上下文切换
- 保持输出质量稳定

别一次性全用上，挑2-3个最适合你的开始用。用熟了再加。

## 常见问题

**这些功能免费版能用吗？**
Projects、记忆、联网搜索、看图等功能免费版大多可以使用，但有额度限制；创建自定义 GPT 等功能需要付费套餐。各功能的可用范围调整频繁，以 OpenAI 官方说明为准。

**Memory 会不会泄露隐私？**
ChatGPT 记住的内容存储在你的账号里，可以在设置中查看和删除，也可以关闭记忆功能。不要让它记住密码、证件号等敏感信息。

**Projects 和自定义 GPT 有什么区别？**
Projects 适合管理某个持续进行的工作（资料、对话都放在一起）；自定义 GPT 适合把一个固定任务做成可重复使用、也可以分享给别人的助手。

**国内怎么用 ChatGPT？**
需要海外网络环境和账号，付费需要海外支付方式，见 [海外服务通关](/categories/海外服务通关/) 分类。
