## 零基础也能用 AI 写代码，但接单要有边界

**结论先说：** 有了 Cursor、Claude 这类工具，零基础的人也能在几周内做出能用的小网站、自动化脚本和小工具，并接一些小单子。但 AI 只是降低了写代码的门槛，需求沟通、测试、交付和售后仍然要你负责；起步阶段应该只接自己能理解、能验收的小项目。

过去，一个没学过编程的人想做出一个能上线的网页，至少要花几个月学 HTML、CSS、JavaScript。现在，用自然语言描述需求，AI 就能生成可运行的代码，报错也可以直接交给 AI 排查。

这让一批非程序员开始接小网站、自动化脚本、数据整理这类外包。适合起步的项目通常规模小、需求清楚、容易验收。

关键在于：**AI 编程工具把写代码的门槛大幅降低了，但没有降低对结果负责的要求。**

这篇文章按顺序讲清楚：从零开始怎么学、用什么工具、怎么接第一单、怎么保证交付质量，以及哪些项目不要碰。

## 为什么AI编程让零基础接单成为可能

先聊一个核心问题：以前学编程为什么难？

因为你要记住语法、理解数据结构、搞定各种框架和库的配置。一个简单的网页应用，光是搭开发环境、装依赖、配路由就能卡住一个初学者好几天。更别提还要理解面向对象、异步编程这些概念。

AI 编程改变了两件事：

**第一，AI把"写代码"变成了"描述需求"。** 你不需要记住语法，只需要告诉AI你想要什么。比如"帮我写一个网页，用户输入一个URL就能抓取页面的标题和描述"，AI 就会给你生成完整的代码。你需要做的事情是：描述清楚、验证结果、让AI修正。

**第二，AI大幅降低了调试成本。** 以前代码跑不起来，你得一行行排查。现在你直接把报错信息复制给 AI，它通常能很快定位问题并给出修复方案。

你可能会说："这不就是 Copy Paste 吗？这样写出来的代码能卖钱？"

答案是：**能。客户买的是"能用的东西"，不是"你亲自写的代码"。**

很多小客户关心的是结果：交付物能用、能上线、能跑起来。用不用 AI，他们并不在意，但出了问题你必须能修。

当然，AI 编程也不是完全没有学习曲线。你需要学的是怎么用 AI，同时要逐步理解代码在做什么。Cursor 的用法见 [这篇 Cursor 教程](/posts/cursor-programming-tools/)，这里就不展开了。

## 工具准备：Cursor + Claude + ChatGPT

工欲善其事，必先利其器。零基础做 AI 编程接单，推荐三件套：

### Cursor —— 你的主力写代码工具

[Cursor](https://cursor.sh) 是目前最适合零基础用户的 AI 编程 IDE（集成开发环境）。它基于 VS Code 改的，但集成了 AI 能力，你可以直接在编辑器里和 AI 对话让它写代码、改代码、解释代码。

它的 Composer 功能（`Cmd+I` 快捷键）是最核心的功能——直接描述需求，AI 就能生成一整个文件甚至一个项目，后面会演示怎么用。

关于 Cursor 和同类工具的对比，见 [Cursor vs Windsurf 对比评测](/posts/cursor-vs-windsurf-2026/)。

### Claude —— 架构设计和复杂逻辑

[Claude](https://claude.ai) 适合做「架构师」。当项目比较复杂、业务逻辑有一定深度时，可以用 Claude 来设计数据结构、设计 API 接口、梳理业务流程。

### ChatGPT —— 文档查询和调试辅助

[ChatGPT](https://chatgpt.com) 适合查文档、写正则表达式、调试 SQL 语句这些「零散活」。它的知识面广，对各种库和框架的兼容性问题比较熟悉。

三个工具各有分工：**Cursor 干活，Claude 规划，ChatGPT 查漏补缺。**

如果你想知道更多 AI 编程工具的区别，可以看看 [AI 编程工具对比](/posts/ai-coding-tools-comparison-2026/)。

## 第一步：学基础——不是学语法，是学怎么问AI

很多零基础的人会问：「学编程第一步该干嘛？是不是先学 Python 语法？」

更实际的回答是：**先学怎么跟 AI 沟通。**

判断 AI 编程能力强不强，有个金标准——**你描述需求的能力。** AI 再厉害，你描述不清楚它也帮不了你。就像一个顶级厨师，你只说"做道菜"，他不知道你爱吃辣还是清淡，怎么做？

所以零基础的朋友，第一步建议做三件事：

### 1. 学会"精确描述"

举个例子，不要说"帮我写个网站"，而是说：
> "帮我用 HTML + CSS + JavaScript 写一个单页面的工具站，功能是把用户输入的文字转换成二维码在页面上显示，界面风格参考 Bootstrap 5 的毛玻璃效果，按钮是渐变的蓝色。"

越具体的需求，AI 给出来的东西越接近你想要的结果。这个能力不需要懂编程，需要的是**结构化思维**——把一件事拆成功能点，按优先级说出来。

### 2. 学会"让AI迭代"

AI 一次写出来的东西很少是完美的。新手常犯的错误是：AI 生成完了就不改了，结果拿到了一个能用但很丑的东西。

正确做法是：先用 AI 跑出来一个 MVP（最小可用版本），然后一步步优化。
> "这个按钮的位置不对，放在页面右上角。"
> "颜色太暗了，换成浅灰色。"
> "加一个加载动画，在生成二维码的时候显示。"

每次只提一个具体的修改要求，AI 就能精准地执行。就像跟一个远程程序员协作，一句话一个指令。

### 3. 学会"看报错信息"

这是很多人怕的东西。但有了 AI 之后，报错信息其实是你最好的朋友——直接复制报错给 AI，它会告诉你问题在哪。

你不必理解报错里的每一个词。你只需要做一件事：**复制，粘贴，等AI回答。**

这三个技能学会了，你就已经具备了"用 AI 编程的能力"。剩下的语法、框架、API 调用，都是在实战中边做边学的。

## 第二步：做第一个小项目

光说不练假把式。第一个项目不要太大，但要有明确的「用户价值」。

### 推荐：做一个工具站

工具站是最适合新手的起步项目。它的特点是：
- 功能单一，逻辑简单
- 不需要数据库和后端
- 纯前端就能搞定
- 确实有人用，能给你信心

这个方向很适合零基础的人练手：纯前端、不需要服务器、做完就能分享给别人用。

举几个例子：
- **文字转二维码**：用户输入文字，页面生成一个可下载的二维码图片
- **Markdown 转富文本**：粘贴 Markdown，实时预览渲染结果
- **字数统计工具**：分析文本的字数、字符数、段落数
- **在线颜色选择器**：选颜色，复制十六进制和 RGB 值

### 实操演示：用 Cursor 做一个二维码工具站

假设要做一个「文字转二维码」工具。打开 Cursor，按 `Cmd+I` 打开 Composer，输入：

> "帮我做一个纯前端的工具站，功能是输入文字生成二维码。要求：
> 1. 使用 qrcode.js 库
> 2. 界面干净，使用毛玻璃效果
> 3. 生成二维码后可以右键保存
> 4. 支持中文输入
> 5. 页面响应式，手机电脑都能用"

AI 会给你生成一个完整的 HTML 文件。你保存到本地，双击打开就能用。

然后你继续迭代：
> "在输入框下面加一个字符数统计"
> "下载按钮改成蓝色渐变"
> "背景加一个淡紫色渐变"

大概 10-15 分钟后，你就有一个能上线的工具站了。

这个项目放到 [GitHub Pages](https://pages.github.com/) 或者 Vercel 上部署一下，你就可以把链接发出去给别人用了。

## 第三步：怎么接单

有了第一个拿得出手的项目，就可以开始接单了。

一个实用的原则：**不要等「完全准备好」再开始，但只接你能理解、能验收的小项目。** 第一个单子通常是几百元的小活，做好它比接大单重要。

### 接单渠道推荐

**国内**

- **闲鱼**：搜索「做网站」「小程序开发」「Python 脚本」，看看别人怎么写服务介绍和报价。小型落地页、简单脚本是常见的入门单。
- **电鸭社区**：国内最大的远程工作社区，接单板块经常有外包需求发布。适合中大型项目。
- **朋友圈/微信群**：熟人介绍的单子往往最靠谱，沟通成本低、信任度高。可以发条朋友圈说明你能帮忙做哪些小项目。

**国外**

- **Upwork**：全球最大的自由职业平台，对新手友好，但前期需要积累评价。价格可以从低开始，逐步提高。
- **Fiverr**：主打小额快速项目，适合卖"AI帮你写一个某某功能"这种服务。
- **CodeMentor**：如果你愿意教别人，这里也可以接辅导的单子。

其他 AI 副业方向的对比见 [用 AI 做副业的 9 种方式](/posts/make-money-with-ai-2026/)。

### 接单的话术模板

第一次接单不知道怎么跟客户沟通？可以参考这个模板：

> "您好，我是做网站和小程序开发的，主要用 AI 辅助编程来提升效率。您的需求我可以做，报价是 XXX 元。交付工期大概 X 天，包含 XX 次修改。如果您有兴趣，我们可以先聊聊具体需求。"

关键词是"AI辅助编程"——既诚实，又能让客户觉得你技术好（效率高）。

## 第四步：交付流程——用AI保证代码质量

新手接单最怕什么？**怕交付的东西质量不行，被客户骂。**

只要抓好下面三个环节，交付质量基本可控：

### 1. 需求确认阶段（最重要）

这是最容易翻车的地方。客户的描述和你的理解经常有偏差。

做法是：**把客户的需求复述一遍，让 AI 写一个功能清单出来，发给客户确认。** 比如：

> "根据我们的沟通，这个项目需要以下功能：1. 登录注册；2. 用户资料编辑；3. 文章发布。请确认是否有遗漏或需要调整的。"

得到确认之后再开始写代码。这一条能避免 80% 的后期修改。

### 2. 开发阶段

每次写代码时，对 AI 提一句："加上适当的错误处理和注释。解释一下你写的这段代码的逻辑。"

这样写出来的代码不是黑盒，你知道每一段在干什么。万一需要手动修改，也不至于完全看不懂。

每次交付前对照一份检查清单过一遍，比如功能是否齐全、手机上显示是否正常、报错处理是否完整，能少踩很多坑。

### 3. 测试和上线

让 AI 写测试用例：
> "帮我写几个测试场景，验证这个登录功能是否正常。考虑边界情况：空密码、密码太短、错误的验证码。"

然后让 AI 帮你部署。现在部署很简单，用 Vercel 或者 Netlify，绑定 GitHub 仓库就能自动上线。不懂部署步骤？直接问 AI："帮我写一个 Vercel 部署指南。"

## 常见项目类型

下面是适合用 AI 编程起步接单的项目类型（单价为闲鱼等平台上常见的报价区间，仅供参考，实际随地区、需求和你的能力差异很大）：

### 1. 企业官网/落地页
**难度：低 | 需求量大 | 单价：500-3000元**
一个简单的展示型网站，几页内容，响应式设计。AI 半小时搞定框架，你花时间调整文案和图片就行。

### 2. 自动化脚本
**难度：中 | 需求量大 | 单价：200-2000元**
比如自动处理 Excel 数据、批量重命名文件、定时发送邮件通知、爬取网站数据。这类需求很多，而且小公司非常需要。用 Python 写，AI 是你的好帮手。

### 3. 数据爬虫
**难度：中高 | 需求量中 | 单价：500-5000元**
爬取特定网站的数据，整理成结构化的 Excel 或数据库。注意：只爬取公开且网站允许抓取的数据，遵守网站的 robots 协议和服务条款，不碰个人信息和需要登录的数据，否则可能违法。零基础不建议一开始就接爬虫单。

### 4. 小工具/小应用
**难度：低中 | 需求量中 | 单价：200-1000元**
在线计算器、二维码生成、PDF 转换工具、图片压缩工具。前端纯静态页面就能搞定，适合练手。

### 5. WordPress/Wix 网站定制
**难度：低 | 需求量大 | 单价：300-2000元**
用 AI 写一些自定义的 CSS、PHP 代码片段，帮客户定制主题。这类需求在外包平台上非常多。

## 定价策略和报价技巧

价格定高了客户跑了，定低了自己亏。下面是一个简单的定价思路（参考）：

**网页类项目 = 500 + (预估天数 × 150)**

比如一个预计 3 天完成的企业官网，报价 500 + 3×150 = 950 元。实际上因为 AI 的辅助，你可能 1 天就做完了，时薪很高。

**脚本/脚本类项目 = 300 + 功能复杂度 × 200**
复杂度 1 就是基本功能，复杂度 3 就是多步骤、多条件。一个中等复杂度的爬虫报价 900 元左右。

报价技巧：

1. **首次报优惠价，后续提价。** 第一个项目便宜点（200-500），换来好评和案例，后面报价翻倍也合理。
2. **先报价后接单。** 不要先说时间再说价格，容易被压价。
3. **标明修改次数。** "包含2次免费修改，超出部分每次加收100元。"这能防止需求无限膨胀。
4. **分期付款。** 定金 50%，验收后付尾款。降低双方风险。

## 零基础接单的典型路径

一个比较常见的起步路径是这样的：

先花几天时间，用 AI 做出两三个能演示的小作品，比如二维码工具、Excel 数据整理脚本。然后在闲鱼或朋友圈挂出服务，写清楚能做什么、不能做什么。

第一单通常是很小的需求，比如帮淘宝店主写一个自动整理订单数据的 Python 脚本。

做的过程中，把需求一步步描述给 Cursor，遇到报错截图发给 Cursor 或 Claude 排查。比做完更重要的是：交付前自己把每个功能测一遍，并且让 AI 解释代码的关键部分，确保出问题时自己能修。

做完几单、积累了好评和案例后，再逐步接更复杂的项目。

这个阶段不要指望收入很高，它更像是带着报酬的学习。随着你理解的代码越来越多，能接的项目类型和单价才会慢慢提升。

会一些基础的 Python 或 JavaScript 后，也可以尝试 [Upwork](https://www.upwork.com/) 等国际平台，但那里竞争更激烈，对沟通和交付质量要求也更高。
