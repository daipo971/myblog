美团的大模型「龙猫」今天上午发布了新一代旗舰 LongCat-2.5。今年 9 月 25 日上线的还只是 Preview 版、没有官方评测；今天是正式版，规格和评测数据一并给齐。定位很明确：一款面向**长程智能体任务**的原生多模态模型——冲着「让 Agent 连续干几个小时的复杂活」去的。

## 规格：1.6 万亿参数，全程国产算力训练

- 总参数 **1.6 万亿**，每个 token 激活约 480 亿参数（MoE 架构）。
- 在 LongCat-2.0 的基础上强化两件事：原生视觉理解和智能体编程。视觉信号被表示成多层级离散 token，和文本一起喂给主干模型统一处理，所以它能「看着图写代码」——官方称之为 Visual Coding，指向交互网页、创意设计、3D 页面这类任务。
- 训练侧：中训练阶段用最长 1M token 的序列做长上下文训练；针对长程任务加入更多长程轨迹数据，并做大规模长程强化学习；一个值得注意的做法是把真实 Agent 执行失败的轨迹转化成可复现、可验证的训练任务，专门补短板。
- 延续 2.0 的「国芯国模」路线：全程在国产算力上完成训练，并针对国产算力做了长上下文训练与 W4A4 低精度推理优化。

## 它主打的活：复杂代码库、完整项目、经营分析

按官方说法，LongCat-2.5 的核心场景是复杂代码库开发和完整项目构建这类端到端工程任务，也就是昨天本站那篇 [从零手写一个会干活的 AI Agent](/posts/build-your-own-ai-agent-tutorial/) 里讲的循环要连续跑很多轮的场景——模型本身的长程稳定性，决定了 Agent 能不能把长任务干完。

另一个强化方向是美团的主业：商业分析。官方技术博客给的案例里，模型能为品牌多渠道经营自主构建渠道利润表，识别出「支付 GMV 增长 23.2%、渠道利润却下降 1.7%」的增长质量问题，再结合清货价值、复购和库存风险给出资源配置建议。美团基于 LongCat 系列做的商家 AI 经营工作台「妙手」，用的就是这条线。

## 评测：官方自报很亮眼，但短板也别装看不见

先说清口径：以下都是**美团官方公布的数据，未经独立第三方验证**。

- 官方口径：多项主流基准介于 Claude Opus 4.8 与 Opus 5 之间，部分评测超过 Opus 5。被重点点名的有 Terminal-Bench v2.1 得分 88.4、BrowseComp 91.9。
- 但同一张官方成绩单上，Program Bench 只有 25.5，低于榜首的 37——真实工程项目的长程构建能力并没有标题里那么全面领先。

所以正确的读法是：它在终端操作、浏览检索类 Agent 任务上自报成绩很强，完整项目级的长程工程仍是短板。等第三方榜单和实际 API 用户反馈出来，再下结论不迟。想系统了解各家 Agent 能力坐标的，看 [AI Agent 完全指南](/posts/ai-agent-complete-guide-2026/)。

## 怎么用：权重已开源，定价也落地了（11 月 11 日更新）

- **在线体验和 API 已经开放**，国内可直接用，不需要海外账号。
- **权重已开源**：11 月 4 日起陆续上传 Hugging Face（[meituan-longcat/LongCat-2.5](https://huggingface.co/meituan-longcat/LongCat-2.5)），美团 11 月 9 日晚正式宣布，采用 **MIT 协议**——可以商用推理、修改和再训练，保留版权声明即可（商标与专利不在授权范围内）。同时上线了 W4A4 量化版（LongCat-2.5-W4A4），并附了国产算力（NPU）的部署说明。
- **但普通读者别惦记下载本地跑**：全量 BF16 权重约 **3.56TB、208 个分片**（本站按 Hugging Face 仓库文件实测合计），是给有集群和国产算力的团队准备的。想用它，走 longcat.ai 在线体验或 API 才是现实路径；量化版门槛低一些，同样偏团队部署场景。
- **定价已经落地**：官方定价页目前是限时价——输入（未命中缓存）**2 元 / 百万 token**、命中缓存 0.04 元、输出 **8 元 / 百万 token**（美元口径 $0.30 / $0.006 / $1.20）。官方标注为限时折扣、未给结束日期，最终以平台实时价格为准。
- **想零成本试手感**：开源当天，编程工具 OpenCode 宣布该模型限时免费两周，免费入口每天限 100 次请求（据智东西 11 月 10 日报道）；累计用量和入口规则以 OpenCode 官方为准。

## 和昨天的两条线正好接上

这两天 Agent 方向的动作很密：昨天 DeepSeek 把内部的超级 Agent 系统开源了（[DeepSeek 开源超级 Agent 原型](/posts/deepseek-superagent-prototype/)），今天美团发布主打长程任务的旗舰模型。一个发「Agent 的组织系统」，一个发「能跑长程任务的模型本体」——Agent 的竞争正在从单点工具，升级到模型和系统一起卷。LongCat-2.5 的权重与定价现已落地，本文上方「怎么用」一节已按 11 月 11 日的最新状态更新。
