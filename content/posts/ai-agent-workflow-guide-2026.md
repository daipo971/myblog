2026年最火的AI概念是什么？不是某个模型，而是 **AI Agent（智能体）**。

简单说，AI Agent 就是让AI不只是聊天，而是**能自己干活**——帮你查数据、发邮件、写报告、监控网站，一套流程全自动跑完。

我之前想过用Python写这些脚本，但太麻烦了。后来发现了 **n8n**，一个开源的工作流自动化工具，拖拽就能搭建AI工作流，完全不用写代码。

这篇就分享我搭的几个实用工作流，从简单到复杂，你复制就能用。

---

## n8n 是什么

n8n 是一个开源的工作流自动化平台，类似 Zapier 但更强的地方是：
- 完全自托管，数据不出自己的服务器
- **支持所有主流AI模型**（OpenAI、Claude、Ollama本地模型）
- 可视化拖拽编辑，不用写代码
- 无限量使用，不像Zapier有额度限制

### 5分钟安装

```bash
# 用Docker一行命令搞定
docker run -d --restart=always \
  --name n8n \
  -p 5678:5678 \
  -v ~/.n8n:/home/node/.n8n \
  n8nio/n8n
```

装完打开 `http://localhost:5678`，注册账号就能开始了。整个过程不到5分钟。

## 工作流1：自动整理每日信息简报

这个是我用得最多的。每天早上自动帮我整理前一天的行业新闻和动态。

**步骤：**
1. 定时触发（每天早上8点）
2. RSS抓取你关注的博客/新闻源
3. 丢给AI（我用Claude）总结要点
4. 生成HTML邮件
5. 自动发送到你的邮箱

n8n里就是拖几个节点的事情：
- `Schedule Trigger` 节点设时间
- `RSS Feed Read` 节点抓取RSS
- `OpenAI` 节点接Claude，让它"请用中文总结以下内容，每条不超过50字"
- `HTML` 节点格式化输出
- `Email` 节点发送

我跑了两个月了，每天早上到办公室打开邮箱就能看到整理好的简报，省了至少30分钟。

## 工作流2：自动回复客户咨询邮件

如果你有个人项目或者小生意，客户邮件经常是重复问题。

**步骤：**
1. Gmail触发器（新邮件到达）
2. AI判断邮件类型（咨询/投诉/合作）
3. 根据类型自动生成回复草稿
4. 存入Google Sheet备查
5. 发Slack通知你审核

**关键设置：** 让AI先分类，不同类别走不同分支。比如"合作"类邮件直接转给你人工处理，"常见问题"类自动回复。

```json
// AI节点的system prompt
你是一个专业的客服助手。请将邮件分为三类：
1. 常见问题 - 用预设模板回复
2. 合作咨询 - 转人工处理
3. 投诉 - 转人工处理且标记紧急
```

这个工作流帮我过滤掉了大约60%的重复咨询，我只需要处理剩下需要人工的邮件。

## 工作流3：AI监控+自动报告

这个稍微进阶一点，但非常实用。

**场景：** 监控某个网站的SEO排名或者竞品动态。

**步骤：**
1. 定时抓取目标网页（HTTP Request节点）
2. AI分析页面变化和新内容
3. 如果发现重要更新，自动生成分析报告
4. 推送到Telegram或微信

我用它来监控几个竞品博客和论坛的热门讨论，有新动向第一时间知道。

## 工作流4：AI内容分发

写一篇文章，自动分发到多个平台。

**步骤：**
1. 手动触发（或检测到新文章发布）
2. 读取你写的Markdown文件
3. AI根据各平台风格改写（小红书口语化、知乎专业风、Twitter英文精简）
4. 自动发布到各平台（通过API）
5. 记录发布日志到Google Sheet

这个我最近才开始用，效果还不错。以前发一篇文章要手动适配三个平台，现在一键搞定。

我的建议：**技术用户无脑上n8n**，免费且可控。不想折腾服务器的可以用Make，性价比比Zapier高。

## 三个实用技巧

1. **AI节点用本地模型**：如果你装了上面那篇[本地AI教程](/posts/ai-local-llm-guide-2026/)的Ollama，n8n可以直接调本地的模型，不花一分钱API费。

2. **错误处理**：每个工作流一定要加 `Error Trigger` 节点，这样出错了它会发通知给你，不会无声无息地挂掉。

3. **分批处理**：如果处理大量数据，记得用 `Split In Batches` 节点分批，不然AI容易超时。
