**结论先说：** 想让 AI 定时、自动地帮你处理重复任务（整理资讯、分类邮件、监控网页、改写内容），n8n 是性价比很高的选择：可以用 Docker 免费自托管，拖拽节点就能把触发器、AI 模型和各种应用串起来。本文先讲安装，再给出四个常见工作流的搭建思路。不想自己维护服务器，可以用 n8n 云端版、Make 或 Zapier；国内用户也可以看看扣子（Coze）。

**说明：** 本文依据 n8n 官方文档整理（2026 年 10 月查阅），节点名称可能随版本变化，以[官方文档](https://docs.n8n.io/)为准。

## n8n 是什么

n8n 是一个工作流自动化平台，定位类似 Zapier、Make，特点是：
- 可以自托管，数据留在自己的服务器上
- 内置 AI 节点，支持 OpenAI、Anthropic、Google、DeepSeek 等模型，也能调用 Ollama 本地模型
- 可视化拖拽编辑，复杂逻辑可以插入 JavaScript 或 Python 代码节点
- 自托管版本不限制工作流数量和运行次数

注意：n8n 采用「Sustainable Use License」，源码公开，个人和企业内部使用免费，但把它作为服务转售给他人有限制，严格来说不属于 OSI 定义的开源软件。

### 前置条件

- 一台电脑或 VPS（建议 2GB 以上内存），已安装 Docker；
- 至少一个大模型的 API Key，或已安装 [Ollama 本地模型](/posts/ai-local-llm-guide-2026/)；
- 要连接的服务账号（邮箱、Google Sheets、Telegram 等）。

### 安装

```bash
# 用Docker一行命令搞定
docker run -d --restart=always \
  --name n8n \
  -p 5678:5678 \
  -v ~/.n8n:/home/node/.n8n \
  n8nio/n8n
```

装完打开 `http://localhost:5678`，创建管理员账号就能开始了。部署在 VPS 上长期使用时，建议绑定域名并配置 HTTPS，否则部分第三方服务的回调（Webhook、OAuth 授权）无法正常工作。

## 工作流1：自动整理每日信息简报

最适合入门的工作流：每天早上自动整理前一天的行业新闻和动态。

**步骤：**
1. 定时触发（每天早上8点）
2. RSS抓取你关注的博客/新闻源
3. 交给 AI 模型总结要点
4. 生成HTML邮件
5. 自动发送到你的邮箱

n8n里就是拖几个节点的事情：
- `Schedule Trigger` 节点设时间
- `RSS Feed Read` 节点抓取RSS
- AI 节点（OpenAI、Anthropic 或 DeepSeek 等模型节点），提示词如「请用中文总结以下内容，每条不超过 50 字」
- `HTML` 节点格式化输出
- `Email` 节点发送

建议先把 RSS 条目数量限制在 20 条以内，避免一次发给 AI 的内容太长，既费钱又容易漏掉重点。

## 工作流2：自动回复客户咨询邮件

如果你有个人项目或者小生意，客户邮件经常是重复问题。

**步骤：**
1. Gmail触发器（新邮件到达）
2. AI判断邮件类型（咨询/投诉/合作）
3. 根据类型自动生成回复草稿
4. 存入Google Sheet备查
5. 发Slack通知你审核

**关键设置：** 让AI先分类，不同类别走不同分支。比如"合作"类邮件直接转给你人工处理，"常见问题"类自动回复。

```json
// AI节点的system prompt
你是一个专业的客服助手。请将邮件分为三类：
1. 常见问题 - 用预设模板回复
2. 合作咨询 - 转人工处理
3. 投诉 - 转人工处理且标记紧急
```

起步阶段建议只生成回复草稿、由你审核后发送，等确认分类和回复准确了，再对少数固定问题开启自动回复。

## 工作流3：AI监控+自动报告

这个稍微进阶一点，但非常实用。

**场景：** 监控某个网站的SEO排名或者竞品动态。

**步骤：**
1. 定时抓取目标网页（HTTP Request节点）
2. AI分析页面变化和新内容
3. 如果发现重要更新，自动生成分析报告
4. 推送到Telegram或微信

适合监控竞品博客、官方公告页、价格页面。抓取前先看目标网站的服务条款和 robots 规则，控制抓取频率。

---

## 工作流4：AI内容分发

写一篇文章，自动分发到多个平台。

**步骤：**
1. 手动触发（或检测到新文章发布）
2. 读取你写的Markdown文件
3. AI 根据各平台风格改写（小红书口语化、知乎专业风、X 英文精简）
4. 有开放发布接口的平台（如 X、Telegram、WordPress）可以自动发布；小红书、知乎等没有公开发布接口的平台，把改写稿发到你的邮箱或飞书，手动发布
5. 记录发布日志到 Google Sheet

注意不要用非官方接口或模拟登录批量发帖，容易被平台封号。

## 不用n8n的替代方案

如果你不想自己搭服务器，也有其他选择：

| 工具 | 类型 | 价格 | 适合 |
|------|------|------|------|
| **n8n** | 自托管 / 云端 | 自托管免费，云端订阅 | 技术用户，运行量大 |
| **Zapier** | 云端 SaaS | 有免费档，按任务量订阅 | 非技术用户，简单场景 |
| **Make** | 云端 SaaS | 有免费档，按操作量订阅 | 可视化复杂流程 |
| **Dify** | 开源 AI 应用平台 | 自部署免费 | 知识库问答、AI 应用 |
| **扣子（Coze）** | 国内智能体平台 | 有免费额度 | 国内用户、发布到国内渠道 |

价格以各家官网为准。简单的选择方法：会用 Docker、运行量大，选 n8n 自托管；不想维护服务器，选 Make 或 Zapier；主要做知识库问答，看 [Dify 客服教程](/posts/ai-customer-service-bot-2026/)。

## 常见报错

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| 重启后工作流和账号丢失 | 没有挂载数据卷 | 按上面的命令挂载 `~/.n8n` 目录 |
| Google、Slack 授权失败 | 回调地址是 localhost 或没有 HTTPS | 配置域名和 HTTPS，并设置 `WEBHOOK_URL` 环境变量 |
| 定时任务时间不对 | 容器时区默认 UTC | 设置 `GENERIC_TIMEZONE=Asia/Shanghai` |
| AI 节点报超时或超长 | 一次传入内容太多 | 用分批节点拆分，或先截取摘要 |
| 工作流不自动运行 | 没有激活 | 编辑器右上角把工作流切换为 Active |

## 三个实用技巧

1. **AI节点用本地模型**：如果你装了上面那篇[本地AI教程](/posts/ai-local-llm-guide-2026/)的Ollama，n8n可以直接调本地的模型，不花一分钱API费。

2. **错误处理**：每个工作流一定要加 `Error Trigger` 节点，这样出错了它会发通知给你，不会无声无息地挂掉。

3. **分批处理**：如果处理大量数据，记得用 `Split In Batches` 节点分批，不然AI容易超时。

## 常见问题

**n8n 免费吗？**
自托管版本免费使用，不限工作流数量和运行次数，只需付服务器和 AI 模型 API 的费用；官方云端版按订阅收费。

**不会编程能用吗？**
大部分工作流可以纯拖拽完成，但安装部署需要会用 Docker，排查问题时看懂 JSON 数据结构会轻松很多。完全不想碰技术的话，选 Make、Zapier 或扣子。

**AI 自动回复邮件安全吗？**
有风险。AI 可能答错或被邮件里的恶意内容误导。建议先生成草稿人工审核，只对固定问题开启自动回复，涉及金钱、合同的邮件一律人工处理。

**可以接国产模型吗？**
可以。n8n 有 DeepSeek 等模型节点，兼容 OpenAI 接口格式的国产模型也可以通过 OpenAI 节点修改接口地址接入，见 [DeepSeek 模型档案](/posts/deepseek-complete-guide-2026/)。
