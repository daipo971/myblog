**结论先说：** DeepSeek（深度求索）是国内最值得先用的通用大模型之一。网页版和 App 免费，用手机号就能注册，国内直连。开发者可以用价格很低的 API，也可以下载 MIT 协议的开源权重自己部署。它适合中文写作、编程辅助、长文档阅读和需要推理的问题。联网搜索和图片理解不是它的强项。这一页按档案格式整理版本、价格、许可证和用法，有新版本时会更新。

## 价格

**普通用户：** 网页版和 App 免费使用，不需要绑卡。官方没有公布固定的每日条数上限，但用户多的时段可能提示「服务器繁忙」，等一会儿或换个时间重试即可。

**开发者 API（V4.1-Flash，每百万 token，官方价格）：**

| 类型 | 闲时 | 高峰 |
| --- | --- | --- |
| 输入 | $0.15 | $0.30 |
| 缓存命中输入 | $0.003 | $0.006 |
| 输出 | $0.60 | $1.20 |

高峰时段为工作日 06:30–09:30 和 11:30–15:30（印度时间），中国公共节假日除外。同时上线的 Search API 和 Fetch API 均为 $0.75 / 1000 次。以上数据来自官方发布信息，整理见 [V4.1-Flash 快讯](/posts/2026-10-18-deepseek-v41-flash/)，实际以 [官方价格页](https://api-docs.deepseek.com/zh-cn/) 为准。

和海外大模型相比，这个价格低一个数量级左右，所以很多国内外开发者把 DeepSeek 当作「默认便宜模型」，只把少数难任务交给更贵的模型。

## 许可证

DeepSeek 近期的主力版本（包括 V4.1-Flash）在 Hugging Face 和魔搭社区（ModelScope）以 MIT 协议发布权重。MIT 是最宽松的开源协议之一，意思是：

- 可以免费下载、修改、商用，不需要向 DeepSeek 申请授权；
- 只需要保留原始的版权和许可声明；
- 官方不对模型输出承担责任。

早期的部分版本代码和权重曾使用不同的许可文件，如果你要商用某个老版本，下载前看清它模型卡里的 License 一栏。

## 国内怎么用

一共三种方式，按难度从低到高排。

**1. 网页版（最简单）**

1. 打开 [chat.deepseek.com](https://chat.deepseek.com)，点「登录/注册」；
2. 用手机号（+86 可用）或邮箱注册，验证码登录；
3. 进入后直接在对话框提问。需要推理时打开「深度思考」，需要查最新信息时打开「联网搜索」。

网页版支持上传 PDF、Word、Excel、PPT、txt 等文件，可以让它总结合同、论文或表格。

**2. 手机 App**

应用商店搜索「DeepSeek」，认准开发者是深度求索。App 和网页版共用账号，聊天记录同步，另外支持语音输入和拍照上传。应用商店里有不少名字相似的「套壳」App，有的还会收费，下载前看一眼开发者名称。

**3. API 与开源权重（开发者）**

- 在 [官方开放平台](https://platform.deepseek.com) 注册、充值，创建 API Key；
- API 兼容 OpenAI 格式，把已有代码里的 base_url 换成 DeepSeek 的地址、模型名换成 DeepSeek 的模型名即可；
- 想本地或私有化部署，可以从 Hugging Face 或魔搭社区下载权重。Hugging Face 国内访问不稳定，魔搭社区下载更快。完整模型对显卡要求很高，个人电脑一般跑的是社区量化或蒸馏版本，详见 [本地部署大模型指南](/posts/ai-local-llm-guide-2026/)。

## 适合做什么

结合官方介绍和公开评测，DeepSeek 比较擅长的方向：

- **中文写作和改写**：写邮件、汇报、文案、标题，语气更接近中文母语习惯；
- **编程辅助**：写脚本、解释代码、根据报错信息定位问题；
- **长文档阅读**：新版本上下文很长，可以一次性塞进整份合同或论文再提问；
- **需要推理的问题**：数学题、逻辑题、方案对比，开深度思考后效果更好；
- **翻译**：英译中尤其通顺，中译英建议人工再过一遍。

不太适合的方向：需要实时、准确引用最新新闻的问题；需要识别照片内容的任务；对内容审核限制敏感的话题（国内模型的审核比海外模型严格）。

## 深度思考模式怎么用

打开「深度思考」后，模型会先输出一段思考过程（灰色文字），再给最终答案。它更慢，但在复杂问题上更可靠。

**建议开启：** 数学和算法题、逻辑推理、复杂 bug 排查、多方案取舍（比如「A 方案和 B 方案该选哪个」）、需要逐条引用长文档内容来回答的问题。

**不必开启：** 简单问答、日常聊天、写作和翻译（开了反而容易啰嗦）、查一个语法或命令怎么写。

一个省时间的用法是先不开深度思考快速问一遍，觉得答案不对劲再打开重问。思考过程本身也值得看：如果它在中途写出「这个假设可能有误」，说明这道题确实有坑，你可以据此判断答案可信度。

提示词写法和其他模型通用：交代背景、给出具体要求、说明输出格式。更多写法见 [提示词进阶技巧](/posts/chatgpt-prompt-advanced-2026/)。

## 局限性

| 局限 | 具体表现 | 怎么办 |
| --- | --- | --- |
| 联网搜索不稳定 | 有时搜不到最新信息，或引用不准确 | 重要信息自己点开来源核对；或换 Perplexity 等专门的 AI 搜索 |
| 图片理解弱 | 网页版上传图片主要提取其中文字，看图描述能力不如 ChatGPT、Gemini | 需要识图时换用支持多模态的模型 |
| 高峰期繁忙 | 网页版可能提示服务器繁忙 | 错峰使用，或改用 API |
| 内容审核严格 | 部分话题会拒答或回答很保守 | 换话题或换工具，不要尝试绕过 |
| 知识有截止时间 | 不开联网时不知道最近发生的事 | 时效性问题打开联网搜索 |

## 和其他模型怎么选

- 只想要一个免费、国内直连、中文好的助手：DeepSeek 或 [Kimi](/posts/kimi-guide/) 二选一，两个都装也可以。
- 主要处理超长文档：DeepSeek 新版和 Kimi 都支持长上下文，可以同一份文件两边各问一次。
- 需要语音、视频等多模态能力：看看 [MiniMax](/posts/minimax-guide/) 和 [阶跃 Step](/posts/stepfun-step-guide/)。
- 写代码为主：DeepSeek 可以当便宜的主力，复杂的多文件重构再考虑 Claude 等付费工具，对比见 [AI 编程工具横评](/posts/ai-coding-tools-comparison-2026/)。

## 常见问题

**DeepSeek 要钱吗？**
网页版和 App 免费，API 按 token 计费。普通聊天用户不需要付费，也没有官方会员。

**DeepSeek 需要翻墙吗？**
不需要。网页版、App、API 都能在国内直连，用国内手机号注册。

**网上卖的「DeepSeek 会员」「DeepSeek 破解版」能买吗？**
不建议。官方没有付费会员，这类商品要么是套壳收费，要么有账号和隐私风险。

**深度思考和 R1 是什么关系？**
「深度思考」是网页版的开关名，早期背后对应的是 R1 推理模型。新版本里它是同一模型的推理模式，用法不变。

**MIT 开源是不是意味着我可以拿它做商业产品？**
可以。MIT 协议允许商用和修改，只需保留许可声明。但你仍要对自己产品的输出内容合规负责。
