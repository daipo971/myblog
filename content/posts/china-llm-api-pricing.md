## 怎么读懂这张表

### 先分清输入、输出和缓存

一次 API 调用要付三笔钱：**输入**是你发给模型的文字（包括提示词和上传的文档），**输出**是模型生成的文字，**缓存命中输入**是你重复发送过的内容（比如固定的人设提示词、同一份长文档反复问）。输出价普遍比输入贵 3–5 倍，所以让模型少说废话本身就是省钱。

缓存价便宜得夸张：DeepSeek Flash 缓存命中只要输入价的五十分之一。如果你每次调用都带着同一份长文档，先确认平台开了上下文缓存，能省掉大头。

### 美元价和人民币价不要直接换算比较

DeepSeek、Kimi、Qwen、GLM、MiniMax、阶跃国际版用美元标价，豆包、混元、阶跃国内版用人民币标价。两边税费、结算方式不一样，直接按汇率换算会失真。正确做法是：**美元组内比美元组，人民币组内比人民币组**，跨币种只看量级。

### DeepSeek 的高峰闲时价

DeepSeek 是唯一分时段定价的厂商：工作日 01:00–04:00 和 06:00–10:00（UTC）是高峰，价格翻倍；其余时间（包括整个周末和中国法定节假日）是闲时半价。北京时间换算过来，高峰大约是工作日 09:00–12:00 和 14:00–18:00。能错峰跑批量任务的，成本直接减半。

### 混元 Hy4 的五折是限时的

Hy4 的 TokenHub 挂牌价是输入 6 元、输出 18 元，2026 年 12 月 31 日 23:59（北京时间）之前走 TokenHub 调用打五折，实际是 3 元和 9 元。折扣只在 TokenHub 这一路、只到年底，2027 年 1 月起恢复挂牌价。

## 怎么选：按场景给建议

- **要最便宜、量大管饱**：DeepSeek Flash 或 MiniMax M3.1 Flash，输入输出都是全场最低一档，适合聊天机器人、批量抽取、日常调用。两者价格相同，DeepSeek 多一个闲时半价，MiniMax 不分时段。
- **要中文长文档、反复问同一份材料**：优先看缓存价。豆包 Seed 2.1 Pro 缓存命中 1.20 元，混元 Hy4 缓存命中 0.30 元且年底前五折，适合带着固定文档反复问的场景。
- **要最强推理、复杂代码和长程 Agent**：DeepSeek V4 Pro（闲时 $0.66 / $1.98）或 Kimi K3.1 Pro（$2 / $10）。Kimi 输出价是全场最高，日常对话没必要上它，留给真正难的任务。
- **要便宜的轻量版**：智谱 GLM-5.3-Flash 约旗舰十分之一，豆包 Seed 2.1 Lite 输入 0.80 元，都是给高频轻任务准备的。
- **只想先免费用**：各家手机 App（DeepSeek、Kimi、豆包、元宝等）本身免费，付费的是 API 调用。先在 App 里试效果，确定要接入自己的应用再开 API。

## 注意事项

- **价格会变，而且变得很快**：本页价格的查阅时间是 2026 年 11 月 7 日。DeepSeek 只在 2026 年 9 月 10 日就调过一次 Flash 的价格，混元的五折 12 月 31 日到期。本页每月更新一次，付款前务必以各厂商官方价目表为准。
- **App 免费 ≠ API 免费**：不要在 App 里用得好好的，就默认 API 也不花钱。API 是按量付费，开通时一般要先充值，余额用完会停服。
- **阶跃 Step 5 的价格分国内外**：国际版 1 美元输入，国内版 7 元输入，两个渠道的计价币种和接入方式不同，选之前先确认自己走哪条线。
- **Kimi 的批量调用有 6 折**：不要求实时返回的大批量任务（比如离线处理一批文档），用批量接口按标准价 6 折结算，适合能等的活。

## 常见问题

### API 的 token 和字数怎么换算？

没有固定公式。英文大约 1 token ≈ 3–4 个字符，中文大约 1 token ≈ 1–1.4 个汉字。估算成本时按中文 1 token ≈ 1.4 字算，宁可多估不要少估。各家平台一般都提供 token 计算工具，正式接入前先拿真实文本测一次。

### 免费额度怎么领？

各家政策不同且经常变，有的给新用户体验金，有的按模型限时免费。本文不列具体额度数字，因为过期后会误导人。开通时直接看平台充值页的说明，以页面显示为准。

### 只做个人小项目，API 一个月大概花多少？

按每天调用几十次、每次几千 token 输入估算，用 DeepSeek Flash 或 MiniMax M3.1 Flash，一个月通常在几美元以内。真正烧钱的是长上下文反复调用和大批量输出，上线前先做一次限额：平台一般都能设每日消费上限。

### 为什么同一家模型 App 免费、API 却收费？

App 是厂商获客的产品，成本由厂商补贴；API 是卖给开发者的算力服务，按使用量结算。两者模型版本也可能不同，App 里的默认模型不一定等于 API 里最贵的旗舰版。
