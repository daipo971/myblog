先给结论：**OpenAI 在 11 月 17 日发布了 GPT-6.2 Astra 与 GPT-6.2 Sol，这是 GPT-6 系列的又一次大版本升级。**Astra 是面向最难专业工作的旗舰，Sol 是面向日常工作的高效款。两款模型即日起进入 ChatGPT Work、Codex 与 OpenAI API。最值得记住的数字是两个：Astra 的 API 价格比上一代便宜 20%，独立评测机构 Artificial Analysis 给 Astra 的综合指数打了 62 分，排在第二，仅次于 Claude Fable 5.2 的 65 分。普通用户不用急着换模型——这次升级先惠及的是付费订阅与 API 用户，免费版与普通 ChatGPT 对话入口这次没有变化。

![插画：深蓝色旗舰光球与暖黄色日常光球悬浮在办公桌上方，象征 GPT-6.2 Astra 与 Sol 两款新模型](/images/gpt-6-2-astra-sol-launch/cover.webp)

## 发布了什么：两款模型，两种定位

OpenAI 这次一次发了两个模型，分工很明确。Astra 的定位是「为你最难的项目准备的前沿模型」，Sol 的定位是「日常工作的高效全能模型」。官方的说法是，两款模型在更难的任务上表现更好，同时用的输出 token 更少——这句话直接关系到付费用户的用量：同样的订阅额度，能干更多活。

入口方面有一个容易踩的坑：**这次两款模型只进入 ChatGPT Work、Codex 和 API，不进入普通 ChatGPT 对话。**ChatGPT Work 是面向团队与企业的版本，Plus、Pro、Enterprise 与 Edu 用户可以在 Work 和 Codex 里用到；开发者可以在 API 里调用 `gpt-6.2-astra` 与 `gpt-6.2-sol`。如果你打开的是普通 ChatGPT 免费版或 Plus 个人对话，找不到新模型是正常的，不是账号出了问题。据 OpenAI 社区公告，Pro 500 订阅用户可以在两个模型上用 Ultrafast 模式，Pro 200 用户则是第一次在 Sol 上获得 Ultrafast。

Astra 的改进集中在三件事上。第一是专业产出：幻灯片、电子表格与文档更贴近行业规范，能按给定的模板与行规出活，法律、销售、金融、会计等领域的文稿直接可用的程度更高。第二是代码与前端：代码更干净，生成的前端在网站、游戏与 3D 设计上效果更好。第三是科研与电脑操作：在终端里做科研流程的能力、操作 CAD 与仿真工具的精细度都有提升，官方甚至用它做了从芝加哥 Marina City 大楼阳台造型到纸灯的完整设计流程。

Sol 的改进更贴近日常：多步骤 Agent 流程更稳，写东西更清楚自然，OpenAI 内部不少员工已经把它当成默认模型。官方在 Cognition 的 FrontierCode 2.0 评测里给出的数据是，Sol 与 Astra 只差 0.5 分，成本却只有 Astra 的五分之一左右；在日常任务评测 LifeVal 里，Sol 的得分超过了上一代旗舰 GPT-6 Astra，成本只有后者的七分之一。换句话说，Sol 这次的卖点不是「最强」，而是「够强又便宜」。

## 价格：Astra 降价两成，Sol 原价不动

价格是这次发布最实在的部分，数字全部来自 OpenAI 官方博客与 API 定价：

| 模型 | 输入（每百万 token） | 缓存输入 | 输出（每百万 token） | 与上一代对比 |
| :--- | :--- | :--- | :--- | :--- |
| GPT-6.2 Astra | 8 美元 | 0.40 美元 | 40 美元 | 比 GPT-6 Astra 便宜 20%，缓存输入降价 60% |
| GPT-6.2 Sol | 2 美元 | 未单独公布 | 10 美元 | 与 GPT-6.1 Sol 持平 |

Astra 的降价幅度要放在两个维度看。按 token 单价算，输入与输出都比 GPT-6 Astra 的 10 美元 / 50 美元便宜了 20%。按「完成一个任务的总成本」算，降幅更大：Artificial Analysis 测得 Astra 跑完一个综合指数任务的加权成本是 4.00 美元，而 GPT-6 Astra 是 6.24 美元，降了 36%。这个差距来自两个因素叠加——单价降了，模型完成同一任务用的 token 也少了。Sol 则完全没涨价，维持 GPT-6.1 Sol 的 2 美元 / 10 美元。

对开发者的实际意义是：如果你的调用量已经不小，Astra 的性价比明显高于上一代旗舰；如果任务难度中等，Sol 的价格只有 Astra 的四分之一，能力却接近 Astra，在很多场景下是更划算的默认选择。订阅用户则不用直接付 token 钱，但能感受到「同样额度干更多活」：官方明确说，两款模型用更少的输出 token 拿到更好的结果，这对按用量计费的 Pro 与企业用户是实打实的利好。

## 跑分怎么看：官方数据亮眼，独立评测更值得信

OpenAI 官方给出的跑分相当亮眼，但全部是厂商自报，要分两层看：官方说法与独立评测。

先看官方说法。在多步骤专业工作评测 Agents' Last Exam 上，Astra 比 GPT-6 Astra 高 5.2 分，成本不到三分之一；比 Claude Fable 5.2 高 5.5 分，成本只有对方的 5%。在科研终端评测 Terminal-Bench-Science 0.1 上，Astra 创下新高，比 GPT-6 Astra 高 9 个百分点，成本不到三分之一。在法律文书评测 Harvey LAB-AA v1.1 上，Astra 的通过率是 Fable 5.2 的两倍多，成本约六分之一。长周期知识工作评测 GDPval v2 上，Astra 比上一代高 6.2 个百分点，同时少用 22% 的输出 token。

这些数字听着很猛，但要注意一个细节：官方对比里关于 Fable 5.2 的 Agents' Last Exam 成绩，脚注写明排除了 9 个用了备用模型的任务。也就是说，跨厂商对比的口径并不完全一致，官方图表的「5% 成本」更多是成本结构的差异，不等于「全面碾压」。厂商自报跑分一向挑对自己有利的口径，看个趋势就好，别当成定论。

再看独立评测。Artificial Analysis 在发布当天就测完了两款模型，数据更克制，也更有参考价值：

| 模型 | 综合指数（满分制，最高努力档） | 每个指数任务的加权成本 |
| :--- | :--- | :--- |
| Claude Fable 5.2 | 65 | 26.54 美元 |
| GPT-6.2 Astra | 62 | 4.00 美元 |
| Gemini 4 Carbon | 60 | 未公布 |
| Claude Opus 5.5 | 59 | 10.04 美元 |
| GPT-6.2 Sol | 57 | 1.01 美元 |
| GPT-6 Astra（上一代） | 57 | 6.24 美元 |

从这张表能读出三个结论。第一，Astra 比上一代 GPT-6 Astra 高了 5 分，从第 13 名左右冲到第 2 名，超过了 Gemini 4 Carbon 与 Opus 5.5，但仍落后 Fable 5.2 三分，OpenAI 还没有夺回第一。第二，Astra 的性价比断层领先：一个指数任务 4 美元，对 Fable 5.2 的 26.54 美元是六分之一还不到，这才是 Astra 真正的杀手锏——不是最聪明，而是「聪明得足够便宜」。第三，Sol 的 57 分与上一代旗舰 GPT-6 Astra 持平，成本却只有 1.01 美元，日常任务用 Sol 几乎是白捡的升级。

分项上也有亮点与短板。Astra 在 AA-3D 三维生成评测里以 1318 分排第一，超过 Fable 5.2 的 1271 分；在 AA-AnalystAgent 的真实财报分析任务里，Astra 五次独立尝试全部答对 62.5% 的问题，创下新高。但在编码 Agent 指数上，Astra 与上一代基本持平，Sol 反而比上一代 Sol 略有下降，而 Fable 5.2 仍以 58 分领先。也就是说，**纯写代码、跑 Agent 改代码这件事，Astra 并没有拉开差距**，重度编程用户不要指望换模型就自动提效。幻觉率方面，两款模型在 AA-Omniscience 评测里的幻觉率分别是 59% 与 55%，仍然很高，重要事实必须人工核对，不能直接照搬输出。

## 安全评级：第一次有模型达到「自我改进 High」

这次发布还有一个不该忽略的部分：安全。OpenAI 同步发布了 GPT-6.2 的系统卡，评估结论写得很直白。两款模型在网络安全能力上都达到 Critical（临界）阈值，在生物与化学能力上达到 High 阈值；Astra 更是 OpenAI 第一个达到「AI 自我改进 High」阈值的对外发布模型——官方的解释是，这个级别相当于给每位研究员配了一名能力很强的额外研究工程师助手。

正因为能力到了这个级别，OpenAI 这次收紧了高风险网络安全协助的防护，同时通过 Daybreak 向防守方开放低限制版本。这对普通用户的影响很小，但对安全研究者与企业安全团队有实际影响：部分合法的漏洞研究与安全测试流程可能被新防护挡住，需要走 Daybreak 的专门通道。对国内读者来说，这部分更多是行业信号：前沿模型的网络安全能力越强，平台的限制只会越收越紧，「拿旗舰模型随便测漏洞」的窗口正在关闭。

## 对普通用户意味着什么：三类人，三种做法

**第一类：ChatGPT 付费订阅用户。**如果你用的是 Plus、Pro 或企业版，在 ChatGPT Work 里可以试试把最难的任务交给 Astra：长报告、复杂表格、按模板做的 PPT、科研文献整理。日常的写邮件、总结、查资料、做计划，Sol 更合适，又快又省额度。普通 ChatGPT 对话用户这次没有新模型，不用折腾，也不用因为「没看到 GPT-6.2」就以为账号有问题。

**第二类：用 Codex 或 API 写代码的开发者。**Astra 的 API 降价 20%、任务成本降 36%，对跑量大的项目是直接省钱；Sol 价格不变、能力接近 Astra，是日常编码的默认选择。但要注意编码 Agent 指数持平这个短板：如果你的瓶颈是 Agent 自主改代码的质量，换模型帮助有限，不如先优化提示词与测试流程。API 调用时认准模型 ID `gpt-6.2-astra` 与 `gpt-6.2-sol`，别被第三方平台上名字相近的旧模型或仿冒名称误导。

**第三类：只看热闹的普通读者。**这次发布真正的行业意义不在「谁第一」，而在「旗舰降价」。Astra 以 Fable 5.2 六分之一的任务成本拿到接近的分数，说明顶级模型的竞争已经从拼分数转向拼「单位成本的智能」。对用户来说，好消息是好模型正在变便宜；坏消息是，各家降价的同时，免费额度与普通入口的升级往往会慢半拍，别指望明天打开免费版就有 GPT-6.2。

## 国内用户注意：可用性与价格都未证实

必须说清楚：**GPT-6.2 在国内能不能直接用、什么时候能用，截至发稿没有官方说法，未证实。**ChatGPT 官方服务一直不对中国大陆地区开放，API 调用同样需要海外支付方式与合规的网络环境。不要轻信「国内直连 GPT-6.2」「免费试用新模型」之类的推广，凡是打着新模型旗号收钱的代充、中转与「直连包」，先核对官方渠道再决定。API 价格按官方美元定价换算成人民币只是参考，实际到手成本还受支付通道与中转服务商加价影响，没有统一答案。

同样要提醒的是，发布当天各家媒体与自媒体的解读很多，跑分口径各不相同。本文的数字以两处为准：OpenAI 官方博客的发布说明，以及 Artificial Analysis 的独立评测文章。凡是只转述二手消息、没有贴出这两处来源的「实测」，可信度都要打折。

## 同日格局：微软也发了七款模型

GPT-6.2 不是 11 月 17 日唯一的发布。同一天，微软在 Ignite 大会上发布了七款自研 MAI 模型，覆盖编码、网络安全、图像生成与实时语音，主打的同样是性价比：MAI Code 2 在编码基准上达到 GPT-6.1 Sol 约 98% 的水平，价格约四成；MAI Cyber 2 Flash 在网络安全评测上以不到 2% 的任务成本追平 GPT-6 Astra。两家同一天出牌，方向出奇一致：不再只比谁的模型最聪明，而是比谁用更低的成本把活干好。对用户来说，这是好事——旗舰降价、平价模型变强，选择变多了，订阅与 API 的议价空间也会变大。

横向看，当前第一梯队仍然是四家：Anthropic 的 Fable 5.2 守着综合指数第一，OpenAI 的 Astra 以性价比紧追，Google 的 Gemini 4 Carbon 与 Anthropic 的 Opus 5.5 分列其后。国产模型方面，阿里同一周发布了 Qwen4-Max，腾讯发布了混元 Hy4 flash，但二者的第三方综合评分与第一梯队仍有明显差距，留待后续单独分析。OpenAI 这次没有发布新一代的「推理架构」或 Agent 平台，GPT-6.2 更像是一次扎实的代际升级：更强、更快、更便宜，但没有改写格局的单一突破。

## 常见问题

**GPT-6.2 和 GPT-6、GPT-6.1 是什么关系？**

GPT-6 是 2026 年 9 月发布的系列，Astra 是旗舰线，Sol 是日常线，之后还有 GPT-6.1 Sol 与 GPT-6.1 Terra 等小版本。GPT-6.2 是这次的大版本升级，Astra 与 Sol 两条线同步更新。命名上容易混淆，记住一点：数字越大越新，Astra 永远比同代 Sol 更强、更贵。

**免费用户能用上 GPT-6.2 吗？**

截至发稿，官方只说 Plus、Pro、Enterprise 与 Edu 用户在 ChatGPT Work 与 Codex 里可用，API 开发者可调用。免费版与普通 ChatGPT 对话没有列入这次发布范围，未证实后续是否下放。

**Astra 和 Sol 该怎么选？**

按任务难度选，不按「越新越好」选。最难的专业工作——复杂代码重构、科研流程、法律与财务文书、按模板做 PPT——用 Astra；日常工作——写邮件、总结、多步骤小任务、轻量编码——用 Sol，成本只有 Astra 的四分之一，能力差距很小。API 用户可以两者混用：难任务走 Astra，批量与日常任务走 Sol。

**从 GPT-6 Astra 升级值得吗？**

API 用户值得：单价降 20%，任务成本降 36%，分数还涨了 5 分。订阅用户则要看入口：你在 ChatGPT Work 或 Codex 里能直接选到新模型，升级是顺手的；如果只用普通 ChatGPT 对话，这次升级与你无关，等后续下放再说。

**跑分里的 62 分、65 分是什么意思？**

这是 Artificial Analysis 综合指数 v5 的分数，综合九项知识、编码、科学与常识评测，最高努力档下测得。分数越高越强，但它主要测英文与文本任务，不能代表中文、语音与多模态表现。看跑分要同时看成本：Astra 的 62 分配 4 美元任务成本，与 Fable 5.2 的 65 分配 26.54 美元，是两种完全不同的性价比。
