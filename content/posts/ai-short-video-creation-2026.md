## 第一步：AI写脚本（1-2分钟）

**工具：** ChatGPT / Claude / 豆包

AI写脚本的关键不是"帮我写个脚本"，而是**给出足够的信息让AI理解你的目标受众和内容定位**。

### 我的Prompt模板

```
你是一个短视频脚本写作专家，擅长抖音/小红书风格的内容。

请帮我写一个60秒的短视频脚本，主题是：{你的主题}

要求：
- 开头3秒必须有钩子（吸引注意力）
- 语言口语化，像朋友聊天
- 每15秒一个信息点
- 结尾有行动号召（点赞、关注、评论）

格式：
【00:00-00:03】开头钩子：
【00:03-00:20】核心内容1：
【00:20-00:40】核心内容2：
【00:40-00:55】总结：
【00:55-01:00】行动号召：
```

### 实测效果

拿这个模板去写，AI生成的内容质量很高。尤其是**开头3秒的钩子**，AI比大多数人想得都好。

**示例：** 我让AI写一个"AI工具推荐"的脚本，它给的钩子是：

> "你有没有想过，每天刷短视频的时间，其实可以用来赚钱？不用你会剪辑，不用你会写文案，AI全帮你干了。"

这个钩子直接击中痛点，完播率明显比我自己写的开头高。

**小技巧：** 让AI生成3-5个不同角度的钩子，选最好的那个。开头决定了观众会不会看完。

## 第二步：AI数字人/配音（2-3分钟）

**工具：** HeyGen / D-ID / 剪映数字人 / ElevenLabs

2026年，AI数字人已经非常成熟了。你不再需要真人出镜，**AI数字人就能帮你完成口播视频**。

### 方案一：AI数字人（推荐）

**HeyGen** 是目前最好的AI数字人工具。上传一张照片或一段视频，AI就能生成一个会说任何话的数字人。

**价格：** 免费版每月1分钟视频，Creator版$24/月

**操作步骤：**
1. 上传一张你的照片（或选择预设数字人形象）
2. 粘贴脚本
3. 选择语言和声音
4. 点击生成

**效果：** 2026年的HeyGen数字人口型匹配度达到了95%以上，不仔细看几乎分辨不出是AI生成的。

### 方案二：纯AI配音

如果你不需要真人出镜，用AI配音就够了。

**推荐工具：**
- **ElevenLabs**：效果最好，声音自然有情感，免费版每月1万字
- **微软Azure TTS**：中文效果最好，有多款自然中文声音
- **剪映AI配音**：完全免费，中文效果不错

### 方案三：免费方案

如果你是零预算起步，推荐用**剪映**：
- 内置AI数字人（免费）
- AI配音（免费，多种声音可选）
- 而且中文支持最好

## 第三步：AI配素材（2-3分钟）

**工具：** Canva AI / Runway / Pika / 剪映素材库

短视频需要画面支撑。AI能帮你生成或找到合适的素材。

### AI生成视频素材

如果视频需要展示某种概念或场景，AI视频生成工具可以帮你做：

- **Runway Gen-3**：文字生成短视频片段，适合做配素材
- **Pika**：简单易用，免费额度多
- **可灵AI（Kling）**：国产工具，中文场景理解好

### AI自动配素材

**Canva AI** 有个很实用的功能——输入文字描述，AI自动匹配视频素材。比手动找素材快得多。

### 免费方案

**剪映素材库** 有海量免费素材，配合AI脚本分段，直接搜索关键词就能找到合适的画面。

## 第四步：AI自动字幕（1分钟）

**工具：** 剪映 / CapCut / Veed.io

字幕是短视频的标配。2026年不做字幕的短视频几乎没人看——因为很多人习惯在静音状态下刷视频。

### 剪映自动字幕（免费）

剪映的自动字幕功能已经非常成熟：
1. 导入视频
2. 点击"识别字幕"
3. AI自动识别并生成字幕
4. 选择字体和样式
5. 完成

整个过程不到1分钟。而且剪映支持**中英双语字幕**，对做海外内容的创作者很友好。

### 高级功能

**Veed.io** 支持更酷的字幕效果——动态字幕、关键词高亮、自动翻译。适合想做更精致内容的创作者。

## 第五步：AI制作封面（1-2分钟）

**工具：** Canva AI / Midjourney / AITWO

封面决定了用户会不会点进来看。AI做封面的效率远超手动设计。

### Canva AI

Canva AI 有一个"AI封面生成器"功能：
1. 输入视频标题
2. 选择风格（科技感、生活化、知识类等）
3. AI自动生成3-5个封面方案
4. 微调后导出

### Midjourney

如果你想要更有设计感的封面，可以用Midjourney生成底图，然后在Canva上加文字。

**Prompt示例：**
```
A minimalist YouTube thumbnail design, AI tools theme, blue and purple gradient background, clean text space on the left, 3D robot icon on the right, 16:9 --ar 16:9
```

## 进阶技巧

### 1. 批量生产

不要一条一条做。**一次做5-10条脚本**，然后统一生成数字人视频，统一配素材，统一做字幕。批量生产能把单条视频的制作时间压缩到5分钟以内。

### 2. 平台差异化

同一个内容，不要直接复制粘贴到所有平台。**针对每个平台做微调**：
- **抖音：** 开头更猛，节奏更快，前3秒必须抓住人
- **小红书：** 封面更重要，文字信息密度更大，适合知识类内容
- **视频号：** 更偏中年用户，语速放慢，内容更深度
- **TikTok：** 英文内容，注意文化差异

### 3. AI分析爆款

用 **ChatGPT** 分析你的数据：
```
分析以下数据，告诉我：
1. 哪类内容的完播率最高？
2. 什么类型的开头最吸引人？
3. 建议下一期做什么内容？

{粘贴你的视频数据}
```
