**Kimi 是月之暗面（Moonshot AI）的大模型，目前最新旗舰是 2026 年 10 月 23 日发布的 Kimi K3.1 Pro。** 它是国产模型，国内直连、不用翻墙，网页、App、桌面端、编程助手和 API 全渠道可用。官方承诺 11 月 4 日前开源全部权重，许可证尚未公布。

这一页是 Kimi 的档案页：版本、规格、价格、开源进度和用法集中放在这里，每次有新版本或新消息都会更新。单次发布的详细解读见文末的相关报道。

| 2026-07 | K3 | 上一代旗舰，K3.1 Pro 沿用其底座 |

## K3.1 Pro 规格速查

| 项目 | 数据 |
| --- | --- |
| 架构 | MoE 混合专家，896 个专家，每次激活 16 个 |
| 参数 | 总参数约 2.8 万亿，每次推理激活约 1000 亿 |
| 上下文 | 100 万 token |
| 输入模态 | 文字、图片、视频 |
| 推理方式 | 只支持思考模式，关闭思考的请求会被拒绝 |
| API 模型名 | `kimi-k3.1-pro`、`kimi-k3.1-pro-highspeed` |

K3.1 Pro 不是从零训练的新模型，而是在 K3 底座上做了大规模强化学习。月之暗面在技术文章里提到，为了安全开源，删除了训练数据中与网络攻击相关的部分，内部漏洞测试成功率因此从 90.5% 降到 81%。

## 成绩：官方说法与独立评测

以下编程类成绩均为月之暗面官方自测，独立机构尚未完整复现：

- **Terminal-Bench 4.0**：65.7%，GPT-6 Astra 为 58.2%，Claude Opus 5.5 为 66.4%。
- **SWE-Marathon v1.1**：51.7%，高于 Claude Opus 5.5 的 46.3%。
- **BenchCAD（3D 建模代码）**：92.7%。
- **OfficeQA Pro v2（金融文档）**：64.4%。
- **幻觉率**：自家事实准确度压力测试中从 K3 的 23.4% 降到 8.3%，不代表日常问答错误率。

独立评测机构 Artificial Analysis 同日给出的智能指数为 **55 分，全球第四**，比 K3 高 11 分；它用自己的流程测 Terminal-Bench 得到 67%，与官方结论基本一致。

## 国内怎么用

1. **网页**：kimi.com，手机号注册即可。
2. **手机 App**：iOS、安卓、鸿蒙都有，应用商店搜「Kimi」。
3. **桌面端 Kimi Work**（3.1.0 及以上）：适合写文档、做 PPT、深度研究。
4. **Kimi Code**：编程助手，用 `/model` 切换到 K3.1 Pro，需要 Plus 及以上会员。
5. **API**：Moonshot 开放平台申请 API Key。

企业版 Kimi Enterprise 默认不开启 K3.1 Pro，需要管理员手动打开。

## 开源进度
