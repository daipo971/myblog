# 05 SEO 与站点架构

目标：每个读者会搜的问题，站内只有一篇最好的答案，并且这篇答案处在一张清楚的内链网里。

## 站点结构：中心页 → 档案页 → 文章

```
首页
 ├─ 6 个支柱中心页（/categories/<支柱>/）
 │    ├─ 档案页 / 系列入口（<名字>-guide）
 │    │    └─ 快讯、教程、评测（反向链接档案页）
 │    └─ 常青文章（教程、对比、场景指南）
 ├─ 新手从这里开始（/start/）
 └─ 数据页（API 价格表、术语表）
```

每篇文章离首页不超过 3 次点击：首页 → 中心页 → 档案页或文章。

## 关键词流程

1. **找词**：从读者问题出发（Telegram 群提问、知乎 / 小红书高频问题、搜索框联想、Search Console 已有展现的词、Bing Webmaster 关键词研究）。
2. **定意图**：同一个词，搜的人想要什么？教程、对比、价格、新闻？意图决定文章类型。
3. **查重**：`grep -ril "关键词" content/posts`。已有文章覆盖同一意图 → 更新旧文，不另开新文。
4. **分配**：一个意图对应一篇文章。在 [backlog.md](backlog.md) 登记「目标关键词」，避免以后重复。
5. **写**：标题含主关键词，description 含主关键词和结论，第一段自然出现一次，小标题覆盖相关长尾词。

### 防止自己抢自己（关键词蚕食）

- 两篇文章的标题主关键词相同 → 必须合并或改成不同意图（例如一篇「怎么注册」、一篇「被封怎么办」）。
- 快讯和档案页：快讯标题带版本号（「Kimi K3.1 Pro 发布」），档案页用产品名（「Kimi 模型档案」），两者互链。
- 每季度用 Search Console 查「同一查询词有多个本站网址获得展现」，有就处理。

## 页面要素

| 要素 | 规则 |
| --- | --- |
| title | 30 字以内，含主关键词；常青文章可带年份；不用夸张词 |
| description | 70–120 字，说清解决什么问题和结论 |
| slug | 英文关键词，不带年份 |
| H2 | 每 400–600 字一个，覆盖长尾问题（「XX 多少钱」「XX 国内能用吗」） |
| 图片 | webp，alt 写清内容，文件名英文 |
| FAQ | 教程、评测必有；问题用读者原话 |
| 更新时间 | 改内容就更新 `lastmod`，页面显示更新日期 |
| 结构化数据 | PaperMod 自带 Article / Breadcrumb；后续可加 FAQ schema（见路线图） |

## 内链规则

- 每篇 ≥ 3 个站内链接：2 篇同支柱 + 1 个中心页或档案页。
- 新文章发布时，回到 2–3 篇相关旧文，在正文或「相关阅读」里加链接指向新文（双向）。
- 锚文本用描述性文字（「Kimi API 价格」），不用「点这里」。
- 快讯第一条相关阅读必须是档案页。
- 中心页按学习顺序列出该支柱所有文章，每篇一句话介绍；新文章发布后同步加进中心页。

## 抓取与收录

| 机制 | 现状 | 维护 |
| --- | --- | --- |
| sitemap.xml | Hugo 自动生成，含中英文 | 无需维护 |
| robots.txt | `layouts/robots.txt`，允许分类与标签页 | 改动前确认不会屏蔽中心页 |
| IndexNow | `.github/workflows/indexnow.yml`，推送到 main 后通知 Bing 等 | 新增目录时检查网址拼接规则 |
| Google | 依赖 sitemap；重要新页可在 Search Console 手动请求编入索引 | 站长操作 |
| hreflang | `.en.md` 与中文版自动关联 | 英文分支负责 |
| 301 | `static/_redirects` | 合并 / 删除文章时必加 |

## 英文 SEO 要点

- 英文标题和描述按英文搜索习惯重写，不是翻译中文标题。
- 主攻长尾：「<model> API pricing」「<model> license commercial use」「how to use <model> outside China」「<model A> vs <model B>」。
- 档案页英文版保持和中文版同步更新。

## 技术健康（每月检查）

- 本地构建无报错：`hugo -d /tmp/pub`。
- 站内死链：构建后扫描 `href="/..."` 是否都存在（见 [09-ai-playbook.md](09-ai-playbook.md) 的检查命令）。
- Search Console「网页索引」报告里的未编入索引原因。
- 页面体验：PaperMod 默认很轻，新增脚本或大图前先考虑速度。
