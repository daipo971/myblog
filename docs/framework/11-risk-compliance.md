# 11 风险与合规

## 内容红线（不写、不推广）

| 类别 | 说明 |
| --- | --- |
| 无审查 / 成人内容生成 | 包括「无审查」AI 图片视频站、NSFW 工具推荐 |
| 博彩、加密货币投机 | 「万物皆可赌」类平台、空投、币价预测 |
| 违法用途 | 黑卡、盗号、绕过实名、深度伪造他人、AI 诈骗教程 |
| 攻击性安全内容 | 漏洞利用的可复现步骤（可以写防御和科普，不写攻击操作） |
| 侵犯隐私 | 人肉、泄露个人信息的工具 |

报道上述领域的新闻事件（例如某平台因 NSFW 被封）可以，但只写事实和对用户的影响，不提供入口和教程。

## 海外服务通关的风险边界

- 说清风险：绕过地区限制通常违反服务条款，账号可能被封、费用可能不退。每篇开通教程都要有风险提示。
- 不教「交出账号密码给别人代登录」的方式；推荐官方兑换链接、礼品卡、App 内订阅。
- 不推荐来路不明的礼品卡、共享账号、低价黑卡。
- 不写具体的翻墙工具配置教程，只说明「需要稳定的网络环境」。
- 这一支柱只放中文端，不做英文版。

## 准确性

- 数据标来源，厂商自报写「官方说法」，第三方跑分写来源和日期。
- 快讯必须有 2 个以上一手来源；只有爆料的不写成文章。
- 发现错误 48 小时内改正，并在更新记录写明。
- 不写和发布时间矛盾的经历。

## 版权

- 图片：用自己的截图、自己生成的图，或官方新闻稿配图（注明来源）。不直接盗用其他网站的图。
- 引用：引用他人文字要短并注明出处、附链接；不整段搬运、不机翻他人文章。
- AI 生成内容：可以用 AI 辅助写作，但必须经过核对，事实、数据、链接都要逐条验证；不批量发布未核对的 AI 生成文章。

## 商业披露

- 联盟链接在推荐处或文末披露：「部分链接为联盟链接，通过链接购买本站可能获得佣金，你付的价格不变」。
- 本站商城链接标注「本站商城」。
- 品牌合作文章标注「合作」，不改变评测结论。

## 政策与监管

- 中国大陆：涉及生成式 AI 服务管理、算法备案等政策的内容，只做客观解读并链接官方原文，不做立场性评论。
- 评论区：自托管评论后端，定期清理广告和违规内容。
- 隐私：本站不收集读者个人信息（除评论区自愿填写的内容）；以后加统计或通讯时，在关于页说明。

## 账号与运营安全

- 推广账号（X、Telegram 等）不用自动关注、刷量、批量私信，避免封号。
- 仓库里不提交任何密钥、token、账号密码；GitHub Actions 用 Secrets。
- 联盟后台、商城后台、Cloudflare 的凭据只由站长保管。

## 风险处理流程

| 情况 | 处理 |
| --- | --- |
| 读者举报内容错误 | 48 小时内核实并改正 |
| 收到版权投诉 | 先下架相关图片或段落，再核实 |
| 平台政策变化导致教程失效 | 文章顶部加「当前状态」提示，尽快更新或标注失效 |
| 敏感事件 | 暂停相关选题，请站长判断 |
