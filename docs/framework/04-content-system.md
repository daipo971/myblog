# 04 内容类型与模板

硬性的字数和必备项在 [CLAUDE.md](../../CLAUDE.md) 的「文章完整度标准」。本文给出每种文章的结构骨架、写法要点和生命周期。
Hugo 模板在 `archetypes/`，用 `hugo new content --kind <类型> posts/<slug>.md` 生成带骨架的草稿。

## 九种文章类型

| 类型 | 类型标签 | archetype | 字数 | 用途 | 寿命 |
| --- | --- | --- | --- | --- | --- |
| 快讯 | 快讯 | news | ≥ 800 | 新模型、新功能、价格或风控变化 | 1–4 周有搜索量，之后靠档案页承接 |
| 档案页 | 档案 | profile | ≥ 1500（表格为主） | 一个模型或产品的全部信息 | 长期，持续更新 |
| 教程 | 教程 | tutorial | ≥ 2000 | 注册、开通、部署、配置的分步操作 | 长期，界面变了就更新 |
| 评测 | 评测 | review | ≥ 2500 | 单个产品深度实测 | 半年到一年 |
| 对比 | 对比 | review | ≥ 2500 | 两个或多个产品横向比 | 每季度更新 |
| 场景指南 | 指南 | guide | ≥ 2000 | 按人群或任务讲怎么用 AI | 长期 |
| 科普解释 | 科普 | explainer | ≥ 1500 | 用人话讲清一个概念 | 很长期 |
| 合集 / 榜单 | 合集 | review | ≥ 2500 | 某类工具的精选清单，每个都要实测 | 每季度更新 |
| 复盘 | 复盘 | guide | ≥ 2000 | 本站或站长的真实数据与经验 | 长期 |

支柱中心页、术语表、价格表这类页面不算文章类型，规则见 [03-taxonomy.md](03-taxonomy.md)。

## 各类型的骨架

### 快讯（news）

```
开头 100 字：发生了什么 + 对普通用户最重要的一点
## 发生了什么        （时间、谁发布、核心参数，表格优先）
## 关键变化          （和上一版或竞品比，变了什么）
## 对普通用户意味着什么  （能不能用、多少钱、要不要换）
## 国内怎么用        （中国模型写入口；海外模型写可用性，链接海外服务通关总纲）
## 参考来源          （一手来源 ≥ 2：官方公告、官方 GitHub / Hugging Face、论文、官方账号）
## 相关阅读          （第一条是档案页）
```

### 档案页（profile）

```
开头 100 字：这是什么、目前最新版本、适合谁、国内能不能直接用
## 一表看懂          （公司、最新版本、开源与否、许可证、上下文、价格、入口）
## 版本时间线        （日期 | 版本 | 要点 | 本站文章链接）
## 价格              （API 价格表 + 会员价格，标来源和更新日期）
## 许可证与商用      （开放权重模型必写）
## 怎么用            （网页 / App / API / 本地部署，国内外分别写）
## 实测与评价        （链接本站评测，没有就写官方说法 + 第三方榜单）
## 相关快讯          （所有快讯链接，倒序）
## 更新记录
```

### 教程（tutorial）

```
开头 100 字：做完能得到什么、要多久、要花多少钱
## 准备工作          （前置条件清单：账号、设备、网络、费用）
## 第 1 步 …         （每步一个小标题，配截图，写清点哪里、填什么）
## 第 N 步 …
## 常见报错与解决    （报错原文 → 原因 → 解决，表格）
## 常见问题          （3 条以上）
## 参考来源          （官方帮助文档）
## 更新记录
## 相关阅读
```

### 评测 / 对比 / 合集（review）

```
开头 100 字：结论（谁该用哪个）
## 结论速览          （一张表：价格、免费额度、限制、强项、弱项、适合谁）
## 测试方法          （测试时间、版本 / 套餐、测试任务、评分标准）
## 逐项实测          （每个维度一个小标题，贴实测输出或截图）
## 价格与省钱方案
## 怎么选            （按读者画像给建议）
## 常见问题
## 参考来源
## 更新记录
## 相关阅读
```

### 场景指南（guide）

```
开头 100 字：这个人群 / 任务用 AI 能省多少事，推荐的组合是什么
## 适合谁、能解决什么
## 推荐工具组合      （免费方案 / 付费方案两套，表格）
## 具体流程          （任务拆成步骤，每步给提示词模板或操作）
## 实际案例          （真实输入输出）
## 注意事项          （隐私、准确性、学术诚信等）
## 常见问题
## 相关阅读
```

### 科普解释（explainer）

```
开头 100 字：一句话定义 + 一个生活中的类比
## 它是什么          （不用公式，用例子）
## 为什么重要 / 对你有什么影响
## 常见误解
## 实际怎么用上这个知识  （例如：知道上下文长度后，怎么写长文档提示词）
## 延伸阅读          （链接术语表和相关文章）
```

## 内容生命周期

```
新闻发生 → 快讯（48 小时内） → 7 天内要点并入档案页 → 档案页长期更新
                                  ↘ 值得深挖 → 评测 / 对比 / 教程（常青）
常青文章 → 每季度检查 → 过时就更新（改 lastmod + 更新记录）
         → 连续 6 个月无展现 → 合并进相关文章（301）或补强
```

### 更新节奏（新鲜度要求）

| 内容 | 检查频率 | 触发更新的条件 |
| --- | --- | --- |
| 档案页 | 每次有新闻 + 每月一次 | 新版本、价格变化、许可证变化 |
| 价格表 / 数据页 | 每月 1 日 | 任意价格变化 |
| 对比、合集 | 每季度 | 有产品大版本更新、价格变化、新竞品 |
| 教程 | 每季度，或读者反馈 | 界面或流程变化、报错变化 |
| 海外服务通关 | 每月 | 风控、支付渠道、地区政策变化 |
| 科普、场景指南 | 每半年 | 推荐工具过时 |

标题里写年份的常青文章，跨年时更新年份（网址不动）。

## 写作要点（所有类型）

- 开头 100 字内给结论。不写「随着 AI 的发展……」这类引子。
- 每 400–600 字一个 `##` 小标题，小标题本身就要有信息量。
- 能用表格的不用段落：价格、参数、对比、步骤清单。
- 数据标来源；厂商自报的写「官方说法」；自己测的写测试时间和版本。
- 截图、实测输出优先于描述。
- 站内链接 ≥ 3：2 篇同支柱 + 1 个中心页或档案页。
- 结尾不写空洞总结，写「下一步该看什么」。
