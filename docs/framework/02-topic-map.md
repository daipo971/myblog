# 02 AI 全领域选题地图

这张地图把「AI 的各个方面」拆成 22 个领域，每个领域写清：归哪个支柱、优先级、写哪些类型的文章、英文做不做、现在覆盖得怎么样。
选题时先在这里定位领域，再去 [backlog.md](backlog.md) 领具体题目；backlog 写完了，就回到这里按「缺口」补新题。

### 归类判断规则（有歧义时按顺序判断）

1. 讲**国内用户怎么开通 / 付款 / 防封**海外服务 → `海外服务通关`。
2. 主角是**中国公司的模型**或**开放权重模型**（无论国内外） → `中国与开源模型`。
3. 主角是**一个或几个具体产品**，核心是「好不好用、值不值」 → `AI工具实测`。
4. 主角是**一个人群或一个任务**（学生、律师、做 PPT、写论文），工具只是手段 → `AI应用场景`。讲概念的科普也放这里。
5. 主角是**海外闭源大厂、行业事件、政策、硬件、研究**，核心是「发生了什么、意味着什么」 → `AI前沿动态`。
6. 主角是**建站、服务器、SEO、赚钱方法** → `建站与副业`。

例：「GPT-6.1 发布」→ AI前沿动态；「GPT-6.1 实测：写代码比 Claude 强吗」→ AI工具实测；「DeepSeek V5 发布」→ 中国与开源模型；「Llama 5 开源」→ 中国与开源模型；「大学生用 AI 写论文」→ AI应用场景；「Claude 国内注册」→ 海外服务通关。

## 每个领域的标准内容组合

一个领域做「完整」，要具备下面这套组合。缺哪块补哪块。

| 层 | 内容 | 例子（AI 编程） |
| --- | --- | --- |
| 中心 | 1 个支柱中心页中的一节，或一个系列入口 | 「AI 编程工具」系列页 |
| 入门 | 1 篇「是什么 / 怎么选」 | AI 编程工具怎么选 |
| 档案 | 每个主要产品 / 模型 1 个档案页或完全指南 | Claude Code 完全指南、Cursor 完全指南 |
| 对比 | 主流产品两两或多方对比，每季度更新 | Claude Code vs Codex、Cursor vs Windsurf |
| 教程 | 高频任务的分步教程 | 用 Claude Code 从零搭博客 |
| 场景 | 按人群或任务的用法 | 非程序员用 AI 写小工具 |
| 动态 | 新版本快讯，链接回档案页 | Cursor 3.0 发布 |
| 数据 | 可持续更新的数据页（价格、跑分、额度） | AI 编程工具价格与额度表 |

## 常青与时效的配比

- 每周中文 3 篇：常青 2 篇（教程、评测、场景、档案更新）+ 快讯 1 篇。
- 快讯只写对读者有影响的：新模型、价格变化、国内可用性变化、风控变化。纯融资、人事新闻只在 Telegram 发，不单独成文，除非是重大事件。
- 每篇快讯发布后 7 天内，把要点合并进对应档案页。

## 英文端选题（给英文分支）

顺序：中国与开源模型档案页 → 已证明质量的评测（视频生成对比、Cursor vs Windsurf、翻译工具对比、Claude Code vs Codex、本地部署）→ 英文独有选题（中国模型 API 价格追踪、开源模型许可证对比、海外如何使用中国模型、中国 AI 公司图谱）。
不做：`海外服务通关` 和 `AI前沿动态` 的英文版，美区 Apple ID、国行 iPhone、Google Play 改区、代充、Muse 国内注册、微信桥接。

## 地图怎么维护

- 每季度复盘时更新「覆盖」列和优先级（依据 [08-metrics.md](08-metrics.md) 的数据）。
- 出现新领域（例如某类产品突然爆发）时，先作为现有领域的子项；连续两个月有 3 篇以上相关文章，再单独成为一行。
- 新增支柱需要站长同意，并同步改 CLAUDE.md、`content/categories/` 中心页和本文件。
